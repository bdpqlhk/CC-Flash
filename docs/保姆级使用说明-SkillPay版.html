可信局域网定位

数据不出局域网：不上云、无账号、不经过任何第三方服务器——请只在家庭 / 可信办公 Wi-Fi 使用，不要把地址发给外网。

访问令牌（可选）

CC设置 一键开启：6 位配对码 + 按来源 IP 指数退避（IPv6 按 /64 聚合，单窗上限 10 分钟），输一次全端透明，电脑本机不受影响；锁定期间正确码也会被拒，稍等再输。

勿暴露到公网

服务监听所有网卡：连着公司 VPN 时同网段主机也能访问你的共享目录，用完请及时停止服务；地址会自动避开 VPN 虚拟网卡。服务端另有上传 / 下载 / WebSocket 并发闸，CSP 只放行局域网媒体与 PDF 内嵌。

分享链接有边界

开启令牌后链接自带一次性授权：只能下载那一个文件、10 分钟有效、下载成功即焚——转发给可信的人即可，对方免输配对码。关闭令牌或换新配对码时旧链接全部作废；对无效链接的反复猜测会按来源 IP 限流，CSP 也只放行局域网媒体与 PDF 内嵌。

① 确认手机和电脑是同一个 Wi-Fi；② 电脑换过网络 IP 会变，改用桌面端提示的新地址；③ 在电脑浏览器打开该地址自检；④ 公司网络可能开了「AP 隔离」，换个热点试。

同一 Wi-Fi 下打开页面的人都能操作——这是「可信局域网」工具的定位。半可信网络（公司/公共 Wi-Fi）请在 CC设置 开启访问令牌；开启后分享链接自带一次性授权，对方免输码、仅能下载那一个文件。

图片、PDF、纯文本（txt/md/log/csv）和音视频都可以：点缩略图或「预览」打开全屏预览层，右上角「关闭」或按 Esc 回到聊天。PDF 在浏览器网页里内嵌查看，桌面壳 / 手机 App 交系统浏览器打开；Office 文档、压缩包等需下载；html/svg/xml 不会以网页形式内联。

支持标题、无序/有序列表、引用、分割线、代码块，以及行内代码、粗体、斜体、删除线和链接。输入框可多行：桌面 Enter 发送、Shift+Enter 换行；手机 Enter 换行，点「发送」提交。

页面顶部会常驻引导条：点右上角「⋯」选择「在浏览器打开」即可正常上传下载。iOS 没有安装包，直接用 Safari 打开电脑地址使用网页版。

服务会自动避开 VPN 虚拟网卡、优先展示真实局域网地址；若仍不对，看二维码弹窗是否列出多个候选地址，点选与手机同网段的那个。

开关在「CC设置 → 悬浮二维码」（唯一关闭入口），重启保持关闭；重新打开连位置一起恢复。停 1.5 秒出码，按住可拖到任意边缘——多显示器也行：拖到哪块屏就吸哪块屏。

「CC设置」→ 打开「开机自动启动」（默认关闭，打开才向系统注册登录项）。注意先正式安装到「应用程序」再开——从 DMG 或开发目录开启会注册临时路径而失效。

会自动换到下一个可用端口（地址栏端口号会变），无需处理；也可停止服务后手动改端口再启动，二维码与地址会跟着刷新。
