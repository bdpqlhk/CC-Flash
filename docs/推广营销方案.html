CC-Flash · 推广营销方案

文档日期：2026-11-16（修订） 版本：面向 v1.2.2 起（四段 tag v1.2.2.1） 原则：零预算内容驱动 · 不吹不黑 · 安全口径先行

一定位与核心卖点

一句话定位：同一 Wi-Fi 下，电脑开服务、手机扫码就能互传文件发消息——不用装 App、不用登录、不走外网的局域网「文件驿站」。

卖点传播话术（口语化，与产品「保姆级」原则一致）
🚀 极致轻量macOS dmg 仅约 4MB（Windows exe 约 3MB），双击即用，比一张照片还小
🔒 数据不出局域网断外网照样传；不上云、无账号、不经任何第三方服务器
📱 对方零成本手机不用装任何 App，扫码打开浏览器就能用
⚡ 速度即路由速度局域网直传，百 MB 秒级，比微信文件传输助手快一个数量级；图片 / PDF / 文本 / 音视频还能在应用内直接预览
🖥 桌面三平台 + 安卓 APKmacOS / Windows / Linux（源码构建）+ Android APK，手机浏览器全平台通吃
📦 开源透明代码可审计，安全模型写在文档里，敢给安全圈的人看
差异化一句话对比 AirDrop（要苹果生态）、微信传输助手（走外网、有大小限制）、LocalSend（要双方装 App）——CC-Flash 是「对方什么都不用装」的那一个。

原则：先修门面，再敲门。流量进来看到半成品会永久流失。

五阶段二 · 冷启动种子（第 2 ~ 4 周）

原则：挑「局域网传文件」有真实提问的地方回答，不做无差别轰炸。每个渠道先潜水看调性，再以「作者」身份诚恳出场。

六阶段三 · 内容与 SEO（第 2 月起，长期）

  • 长尾词库：「局域网传文件工具」「手机传电脑免软件」「AirDrop 安卓平替」「不走外网的文件传输」「微信传输助手替代」「tftp 替代品」「办公室文件共享」——围绕写 8~10 篇；
  • 发布矩阵：知乎专栏为主阵地，同步掘金 / CSDN / 博客园 / 公众号（同文多发，文末统一挂 GitHub 链接 + UTM 参数区分来源）；
  • 技术向深度文（给开发者看，涨 Star 最有效）：
    • 《用 Tauri 写一个约 4MB 的跨平台工具：托盘、单实例、开机自启的坑》
    • 《局域网传文件为什么不能直接用 mDNS？—— LocalSend / AirDrop / 微信面对面的发现方案对比》
    • 《我们如何用 4 个 GitHub Secrets 搞定 Android 四架构签名发版》（把本仓库真实踩坑史写成故事）
  • SEO 基建：若后续做官网落地页（阶段五），部署到独立域名并提交 Google Search Console / 百度站长；GitHub 仓库页本身也是高权重页面，README 关键词密度要够。

七阶段四 · 口碑自传播（第 2 ~ 3 月）

  • 产品内分享入口：「关于」卡加一行「🎁 觉得好用？把地址发给同事」——复制一段自带下载链接与三步说明的安利话术（复用分享话术模板机制，进 config.js）；
  • 企业/办公室场景模板：写一篇《给团队部署一个内网文件中转站（5 分钟）》，投喂给运维/效率类公众号——场景化比功能列表转化高 10 倍；
  • 用户案例征集：Release 或 README 挂「我用 CC-Flash 做了什么」issue 区，收集到的案例做成合集文二次传播；
  • 跟进机制：Issues/讨论区 24h 内响应（冷启动期口碑 = 响应速度），每个已解决的 Issue 都是潜在的传播素材。

八阶段五 · 品牌与生态（第 4 月起）

  • 官网落地页：独立域名（如 cc-flash.dev / ccflash.xyz），单页站：GIF + 三平台下载 + 文档链接——所有渠道统一挂这个地址（专业感与 SEO 双收）；
  • 包管理器收录：Homebrew Cask（macOS 用户「brew install」心智）、winget（Windows 官方源）、scoop、AUR——每个渠道都是稳定的长尾下载源；
  • awesome 列表 PR：awesome-tauri、awesome-selfhosted、awesome-rust 等，一次 PR 长期引流；
  • i18n：应用界面英文版（配合英文 README），打开国际市场（LocalSend 的主战场就是国际）；
  • Hacker News / Reddit（r/selfhosted、r/LocalLLaMA 不对口，选 r/software、Show HN）：英文门面齐备后再投，Show HN 一次就够，质量决定生死。

十一风险与合规口径

安全口径（所有渠道统一，一字不改）本工具面向可信局域网（家庭/办公室）：默认同一网络的人都能查看、下载、删除共享文件。半可信网络请在电脑端开启访问令牌（6 位配对码、按来源 IP 指数退避、IPv6 按 /64 聚合且单窗上限 10 分钟、本机免输）；分享链接为单文件一次性票据（10 分钟、下载一次即焚、轮换令牌全部作废、无效票据按 IP 限流）。服务端有上传 / 下载 / WebSocket 并发闸，CSP 只放行局域网媒体与 PDF 内嵌。请勿在公共 Wi-Fi 使用，勿把地址发给外网人员。默认无密码是定位选择，不是疏漏——这句话先说清楚，避免被安全社区反噬。
  • 不黑竞品：对比 AirDrop/微信/LocalSend 只讲差异，不说「替代/吊打」；被反问时用「场景不同」回应；
  • 不夸大：「0 流量」类表述要严谨（配对/检查更新走互联网，传文件不走）；
  • 企业场景：主动提示需与公司 IT 确认（AP 隔离、安全策略），避免用户在办公网踩线；
  • 版权：演示用文件、视频 BGM 注意授权；截图里的真实文件打码。
