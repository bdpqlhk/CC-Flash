Integration Proposal · 周边设备 × 直发 × 消息发送

把三处跳转，收成一个
消息工作台

现在「周边设备」是一个页面、「给周边设备发消息」是一个弹窗、「消息发送」是另一个页面。整合方案把它们收进同一个工作台：左侧设备栏选目标，顶部目标条确认，底部输入栏直接发，时间线给出回执。聊天室不动，后端不改，浏览器仍保持无发现的原始聊天页。

一个页面 设备 / 目标 / 聊天 / 文件去掉 周边设备独立页 + 直发弹窗保留 聊天室 / 文件 / 剪贴板改动 前端为主 · 2–3 人日
已落地：桌面消息页左侧设备栏 + 设备入口/目标提示 + 直发回执；手机 App 四页（发送 / 设备 / 文件 / 设置）+ 底部「设备」页（雷达 + 设备清单 + 手动发送）；浏览器保持原聊天室。聊天、文件、共享剪贴板不变，后端 0 改动。
01 · Current Pain

为什么现在看起来“散”

同一件事被拆成三套上下文，每套都有自己的入口、返回和状态。

Context 1
周边设备页

看设备、收藏、扫码。点设备后进入另一个弹窗。

→
Context 2
给设备发消息弹窗

文件 / 文本 / 剪贴板三选一；发完关闭，回到设备页或聊天页。

→
Context 3
消息发送页

真正的时间线、文件抽屉、聊天输入在这里；直发记录不在这里。

目标不清楚：输入框到底发给“房间”还是“某个设备”？只能靠用户记住刚才点开了哪个弹窗。
重复入口：桌面同时有「周边设备」页和聊天页顶部设备条；手机有「发现」Tab 和发送弹窗。
回执丢失：弹窗关闭后，时间线里没有“我发给了谁”的明确记录。
02 · Idea

一个工作台，三个固定区域

把“设备”变成目标选择器，把“直发弹窗”变成输入栏的一种状态，把“聊天时间线”作为唯一反馈面。

Zone 1 · Devices

左侧设备栏

  • 本机共享 + 周边设备
  • 在线/忙碌、收藏、刷新
  • 点设备 = 选中目标，不是打开弹窗
Zone 2 · Target

顶部目标条

  • 始终显示“发送到：本机共享 / 设备 A”
  • 输入栏旁再有目标 chip
  • 一键切回本机共享
Zone 3 · Timeline

聊天 + 回执 + 文件

  • 房间时间线不动
  • 直发成功追加一条本地回执
  • 文件抽屉/手机面板保留
关键取舍：直发仍投递到对方公共聊天/共享目录（与现在一致），不引入私聊后端；本机时间线追加“已发送到 X”的回执，让用户在同一处看到结果。

07 · Implementation

前端整合，后端 0 改动

复用现有设备发现、直发接口和聊天时间线；只调整信息架构与状态。

09 · Trade-offs

取舍与边界

整合不是把入口藏起来；设备栏/目标条必须始终可见，用户才不会“找不到周边设备”。

!
导航变化

桌面去掉「周边设备」侧栏入口，老用户可能找不到。缓解：消息页左栏常驻设备区；手机顶部有「全部设备」；扫码 / 复制地址仍走顶栏与服务中心，不在设备栏底部重复。

!
直发不是私聊

现有直发会进入对方公共聊天/共享目录，同网段可见。回执和目标 chip 要明确写「发送到设备」，避免误以为是私聊。

!
设备为空/离线

左栏/横条给出空态，并提示用顶栏扫码或复制地址；目标设备离线时禁用直发并提示切回本机；不要保留离线目标。

!
目标状态污染

目标 device 对象可能在轮询中消失；用 id 匹配最新 peers，目标消失即回落本机共享并 toast；发送前再校验地址/端口。

!
手机端标签减少

推荐 2 标签是为了缩短路径；如果坚持 3 标签，用保守变体：发现只做目录，点设备后切到发送并选中目标，不再弹窗。

10 · Conclusion

一句话版本

把“设备”变成输入栏的目标，把“直发”变成发送页的一种状态，把“回执”留在同一条时间线。

桌面：消息发送页 = 左侧设备栏 + 顶部目标条 + 聊天时间线 + 共享文件抽屉；点设备只切换目标，直发不弹窗。手机：底部「设备」页（雷达 + 设备清单 + 手动发送）；推荐底部只留「发送 / 设备 / 文件 / 设置」。浏览器：保持无发现的原始聊天室。聊天、文件、剪贴板全部不动，后端 0 改动。

11 · Final

最终落地差异（v1.2.3）

方案主体已按本文实现；以下是与原稿的几处收敛。

1. 设备栏不再重复扫码 / 复制最终版左栏为本机身份卡 + 雷达盘 + 附近设备列表（在线 / 忙碌 / 最近活跃），底部二维码与复制地址已移除——顶栏、服务中心、二维码弹窗已经覆盖，重复入口反而增加视觉负担。
2. 手机 App 四页底部只有「发送 / 设备 / 文件 / 设置」；底部「设备」页（雷达 + 设备清单 + 手动发送）。手机浏览器不渲染标签，仍是原聊天室单页。
3. 直发范围桌面 / 手机 App 选中设备后，文本走对方 /api/chat、文件走对方 /api/upload，本机时间线追加回执；共享剪贴板仍走共享槽，不绑定单台设备。
4. 布局桌面侧栏 176px、设备栏 200px、文件抽屉 320–380px；981–1180px 抽屉改覆盖层，≤980px 进入窄屏。
