CC Flash · 整个过程历史改动记录

时段：2026-11-19 · 版本：v1.2.4 安全加固 · 与《技术实现文档》《需求设计文档》《后期规划》配套阅读
本段主题全代码、全平台深度检查后的集中修复：系统剪贴板同步改为可选、移动端本机令牌、桌面局域网开关恢复、WS 退避、限流与慢客户端、发布链路、Android 17 权限、数据落盘一致性与构建瘦身；同时更新 README / docs / 应用内介绍页，并美化「N 条新消息」浮动胶囊。

一、隐私与安全

  • 系统剪贴板自动同步默认关闭：新增 CC设置「系统剪贴板自动同步」开关（持久化 wft-clip-sync + Rust pref）；开启后仍只在页面可见时同步。此前默认开启会把用户复制的密码/验证码持续上传到无鉴权的局域网接口。
  • 凭据黑名单：isSecretClip() 对访问令牌、当前码与全部对方配对码做精确比对，命中则自动发布与 paste 回传都跳过；「复制令牌」不再随剪贴板同步外发并落盘。
  • paste 回传收窄：全局 paste 监听只在聊天输入框（.tx-input）触发回传；配对码、昵称、日志搜索等输入框不再外发。
  • 共享剪贴板远端鉴权：非本机来源在未开启访问令牌时禁止 GET/POST /api/clipboard；写入按来源限流 240 次/分钟（IPv6 /64 聚合）。
  • 移动端沙箱：Android/iOS 首次启动自动生成本机访问令牌并原子落盘；mobile_loopback_locked 让 127.0.0.1 也需校验，同机其他 App 无法再读写删除共享目录/剪贴板或停服。壳内通过 control_status_cmd 自动取码。
  • 静态页 CSP：浏览器版下发完整 script-src 'self'; object-src 'none'; base-uri 'self'; frame-ancestors 'self' 等策略（样式保留 inline，图片/媒体允许 data:/blob:，connect 允许 ws:）。
  • 发布链路：缺 Apple/Windows 签名 Secrets 时 publish job 报错并保持草稿，不再以 prerelease 公开；Windows 空证书变量不再注入构建环境；应用内更新检查跳过 prerelease。

二、稳定性与可用性

问题修复

单台设备可占满 16 上传 / 32 下载许可增加单来源并发配额（上传 4、下载 8；IPv6 /64 聚合）；下载流每块 45s 空闲超时

三、跨平台

  • 桌面局域网入口恢复：CC设置 通用卡片新增「局域网访问」开关；所有「去发现页开启」文案改为「CC设置」；托盘「打开网页」在安全模式下使用 127.0.0.1（新增 web_url()）。
  • 地址选择：lan_ip() 扩充虚拟网卡过滤（VirtualBox / VMware / Hyper-V / ZeroTier / WireGuard / WSL 等），169.254 链路本地降为末位候选，CGNAT 次优先。
  • IPv6：link-local probe 回包保留 scope id（v4/v6 两条路径统一 dst.set_port()）。
  • macOS：全屏关窗改为固定等待 700ms 再 hide，不再以 is_fullscreen() 提前为 false 判断动画结束。
  • Windows：保留设备名过滤补充上标数字 COM¹/COM²/COM³、LPT¹/²/³；下载落盘同样的消毒逻辑同步。
  • Android：MainActivity 在 Android 16+ 运行时申请 ACCESS_LOCAL_NETWORK（与通知权限合并请求）；前台服务配额超时的 onTimeout 先发「保活已暂停」通知再 stopSelf。
  • Unix 文件名：safe_rel_path / 文件列表只在 Windows 归一化 \，避免 a\b.txt 与 a/b.txt 串文件。
  • 下载文件名：Content-Disposition filename* 改用 basename + NON_ALPHANUMERIC 完整编码，含 %、子目录、单引号的文件名不再生成非法头。
  • iOS：仍不提供原生安装包（无 gen/apple、CI iOS job 注释）；网页版限制、本地网络权限与 ATS 调试脚本口径已在文档中明确。

四、前端体验

  • 窄窗桌面（<980px）把设备入口放到聊天头部（与共享文件同一行，只显示「设备」），点击后在头部下方内联展开同一套设备面板（Teleport，不弹窗）；选中设备自动收起。设备栏雷达保留「扫描雷达」标题、去掉雷达内空态文字，直径 132→156px（面板内 146→184px），并新增在线/忙碌/离线图例。
  • 「N 条新消息」浮动胶囊重做：实心强调色渐变 + 白色粗体 + 下箭头 SVG + 更大触控面积 + 出现动画，解决旧样式在深色底上低对比看不清的问题。
  • 配对弹框「稍后再输入」改为 60 秒内不再自动弹出（pinSnoozeUntil）；401/429 不再把可达的服务误判为失联。
  • 直发批量文件遇到 401/429 立即中止整批并提示更新配对码/稍后再试，不再用旧码把所有文件打一遍触发对方 IP 锁定。
  • 切换电脑地址会提示已取消的未完成上传数量；引用快照在切换会话时清空，避免把 A 电脑的消息带进 B 电脑。
  • 目录超过 8 层的文件在选择/拖入时提前过滤并提示数量；回到前台重新申请 Wake Lock/保活视频。
  • 复制/悬浮码诊断落盘改为 wft-diag=1 时才启用；pet 在场轮询 250ms → 400ms。
  • 单条消息上限由 2000 提升为 200000 字符（前后端同口径 Unicode 计数）；输入栏实时字数、超限红色提示并禁止发送；服务端超限返回 400（不再静默截断）。聊天历史增加 200 万字符总量预算，持久化写入按 300ms 合并，防止超大消息拖垮内存/磁盘/全量拉取。
  • 应用内介绍页、FAQ、设置页文案同步：剪贴板默认关闭、桌面局域网开关、移动端本机令牌、更新只认正式版。

五、构建瘦身

  • Rust release 显式 strip=true / lto="fat" / codegen-units=1 / opt-level="z" / panic="abort" / debug=false / incremental=false，构建脚本单独 opt-level=3。
  • 前端生产构建 drop console/debugger、关闭 sourcemap、esbuild/js minify、删除未引用 discover.svg；dist 主包约 291 KB（gzip 115 KB），CSS 约 96 KB（gzip 18 KB）。
  • 二进制与安装包体积以本机构建实测为准；Windows/Android 产物沿用同一套 Rust/前端裁剪。
