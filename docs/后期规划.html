三v1.2.x · 质量与安全打磨（1 ~ 2 个月）

3.1 主菜：不可信网络防护（P0）

现状：默认无密码（可选访问令牌已落地：6 位配对码 + 指数退避 + 一次性分享票据），公共/半可信 Wi-Fi 下同网段任何人都能操作——这是文档里明说的边界，但推广后会成为最大差评来源。剩余缺口是 HTTPS 与默认策略提示。

项方案优先级
配对码模式✔ 已实现（v1.1.4，超出原方案）服务端生成 6 位访问令牌，持久化防静默失效；全部 /api/* 与 WS 均需配对（比原方案只保护写接口更严）；配对尝试带指数退避防爆破（锁定窗内正确码也拒，防 Accept 伪造绕过）；桌面端设置页常驻显示/复制。剩余项：检测到公共 Wi-Fi 特征时提示开启✔
控制接口令牌✔ 已实现（替代方案）控制接口已收紧为仅回环来源（/api/control/* 非本机一律 403），局域网设备无法启停/读日志，无需再引入 X-Token；另提供 open_lan 安全模式（仅监听 127.0.0.1）✔
HTTPS 自签 + 扫码信任自签证书随服务生成，二维码带上证书指纹，手机首次扫码即信任（消除「HTTP 明文」在推广后的安全性质疑）P1

3.2 配菜（P1）

  • 传输历史：本地记录最近收发（不含文件本体），解决「刚才那个文件呢」；
  • 断网自愈增强：✔ 已实现WS 看门狗强制重连 + 失联/恢复状态机（清空与全量重载 + 恢复提示），手机页面断连后自动按原地址恢复；
  • 路径安全回归测试集：✔ 已实现内置 e2e（裸 TCP 全链路：乱序并行/续传/完成记录/下载 HEAD/Range/416/路径穿越加固断言）；fuzz 边界用例仍可继续扩充；
  • 小尾巴清零：前后端大小单位表统一（ humans/fmtSize 已同步）；日志文案一致性已过一遍（并行分片降噪 + 关键事件留存）；
  • 系统通知：上传完成 / 服务启动失败推系统通知——tauri-plugin-notification 已注册进依赖，只差调用，约 0.3 天；
  • 托盘「复制地址」：托盘菜单加一项复制 IP:端口，少开一次主窗口，约 0.2 天；
  • 删除进回收站：硬删除改为移入 .trash/（复用现有隐藏目录规则），可选保留 N 天 / 手动清空——防手滑，约 0.5 天；
  • 列表搜索：文件页本地搜索框（纯前端过滤），文件多了是刚需，约 0.2 天；
  • 轻量 PWA：apple-touch-icon + manifest + 「添加到主屏幕」，手机桌面一键进共享页；Service Worker 离线缓存暂不碰（复杂度不轻）。

五v2.0 · 生态演进（第 6 月起）

  • iOS 真机包：依赖 Apple 开发者账号（$99/年，决策点见第八节）；workflow 已留注释模板，账号到位即可启用；iOS 需做 Bonjour 权限声明（NSLocalNetworkUsageDescription + _http._tcp 服务声明）；
  • 应用内自更新：tauri-plugin-updater（遗留清单第二项）：后台下载 + 自动重启，前置 minisign 签名密钥与 latest.json 托管（GitHub Releases 即可）；与现「检查更新跳转下载」并存，老用户平滑过渡；
  • 应用市场上架：Google Play（AAB）+ 国内主流商店（华为/小米/OPPO/vivo，需软著与上架材料）——上架版本建议走「配对码默认开」的安全姿态；
  • 国际化 i18n：界面英/日文（vue-i18n），配合推广阶段五打开国际市场；文档英文版同步；
  • 设备间互传（谨慎评估）：手机 ↔ 手机直传（无电脑参与，LocalSend 核心场景）——需要「谁当服务端」的UX 设计，列为探索项，先小范围原型再定。

九明确不做（范围红线）

以下方向一律不碰——它们每一个都会把项目拖离「轻量局域网工具」的定位：
  • ❌ 账号体系 / 云存储 / 公网中转：那就变成了网盘，与「数据不出局域网」的根本卖点冲突；
  • ❌ 双向文件夹同步：一致性深坑，是 Syncthing/Resilio 的地盘；
  • ❌ 音视频通话 / 屏幕共享：完全另一类工程；
  • ❌ 内嵌广告 / 推送弹窗：口碑红线；
  • ❌ 功能型 fork 追求大而全：新功能一律过「是否服务同一 Wi-Fi 传文件主场景」这一问；
  • ❌ 上传断点续传 / 分片上传：整文件直传是 v1.1.8 的刻意取舍（中断即整份重传、半截即时清理），分片会把复杂度与维护成本带回桌面；下载侧 Range 断点续传不受影响（那不是分片上传）。
