CC Flash · 2026-11-25 全量审查与发布/保活加固

版本：v1.2.8+（本地 main 已含本轮修复，待发 v1.2.9）· 本轮对 Rust 服务端、Vue 前端、Android/iOS/桌面/浏览器与发版链路做全量审查；与《技术实现文档》《需求设计文档》《保姆级使用说明》配套阅读。
本轮重点修复未认证慢连接/慢 body 导致的 DoS、IPv6 link-local 限流误伤、剪贴板 DELETE 无限流、发现协议地址迁移劫持；补齐 Windows PFX 签名、未签名 Release prerelease 策略、WebView2 离线安装器、Android connectedDevice 保活；修复移动端失联恢复、上传洪峰、预览竞态、直发看门狗与票据预取；补齐全平台字体 token 并完成三页 dir-2 真实视口复核。

一、服务端安全与可用性

问题修复
发现协议 IPv6→IPv4 迁移只要求“有一方令牌为空”，已知 id 可把发送目标劫持到攻击者 IP 并窃取配对码。迁移必须双方令牌非空且一致；旧版空令牌不迁移。
body 闸门在鉴权前占许可，32 条慢 POST body 可让聊天/剪贴板/分享全部 429。鉴权先于闸门；按来源限 4 条 + 30s 超时，超时/断连释放许可。
axum::serve 无连接数上限、请求头无读超时，未认证空连接即可耗尽 fd。自定义 accept 循环：连接信号量 128、HTTP 请求头 10s 超时、关闭时 1s 宽限后中止；WebSocket 升级保持可用。
IPv6 link-local（fe80::/64）所有设备共用限流桶。link-local 改用完整地址做 key；全局/ULA 仍保留 /64 聚合；发现/PIN/上传/下载/聊天/票据同步生效。
剪贴板 DELETE 无限流，空删除也落盘/广播。复用 clip_admit；空槽直接返回，不写盘不广播。
set_share_dir_cmd 与异步 start() 无互斥：路由用旧目录、票据/状态用新目录。共享目录切换与 start/stop 共用生命周期锁（try_lock，避免 UI 长时间阻塞），运行中/启动中拒绝切换。

二、发版与平台

问题修复
release.sh 私钥守卫漏 base64 编码 JKS（公开仓库可泄露 Android 发布密钥）。增加 base64 解码魔数检查与 key.properties/keystore.properties 文件名拦截。
FORCE_REPUBLISH=1 无法重建已存在 tag，恢复路径失效。确认 Release 未公开后删除远端旧 tag 再重建，重新触发 Actions。
macOS 只配证书、缺公证凭据时 stapler 必然失败。公证四件套只注入非空值；缺凭据时跳过 stapler 并 warning。
Windows PFX 签名未接入 Tauri：只注入环境变量，配置 Secrets 反而让 Authenticode 复核失败。workflow 用 Import-PfxCertificate 导入 PFX，生成 certificateThumbprint/digestAlgorithm/timestampUrl 配置并通过 --config 传给 Tauri。
未签名/未公证桌面产物被当作正式版，更新检查会推给所有用户。缺签名时仍公开发布，但 Release 标记为 prerelease，update.js 跳过；说明中注明安装方式。
Windows 安装器依赖在线下载 WebView2。为控制安装包体积，webviewInstallMode 保持 downloadBootstrapper；Windows 10/11 通常已自带 WebView2 运行时。
Android 15+ dataSync 前台服务 6h/24h 配额导致数小时后静默停止。切换为 connectedDevice 前台服务（声明 FOREGROUND_SERVICE_CONNECTED_DEVICE + CHANGE_WIFI_STATE/CHANGE_NETWORK_STATE），不再受该配额限制；保留 Wi-Fi/CPU 锁与忽略电池优化。

九、全量审查修复与文档同步

问题修复
LAN 上传可执行文件后，桌面“打开”调用系统默认程序，存在用户点击后执行代码的风险。前后端同时拦截可执行/脚本/快捷方式类型；只允许“在文件夹中显示”，Rust open_path_cmd 另检查 Unix 可执行位。
悬浮球导入直接写最终文件名，半截文件可被其他设备下载，删除/崩溃会留下假成功或残留。改为隐藏 .ccimport-*.ccpart 临时文件，校验源大小、fsync 后通过硬链接/原子 rename 转正；临时文件不进入列表，启动清理可回收。
诊断包 README/UI 承诺不含聊天/文件名，但 logs.txt 原样包含聊天预览、文件名、共享路径与 IP。诊断日志移除聊天/文件事件正文，替换共享路径并掩码 IPv4/IPv6；增加脱敏测试，同步 README/介绍页文案。
访问令牌 enabled 标记写失败被吞掉，重启后可能出现“关闭标记 + 码值文件”而静默失去保护。write_pin_enabled 返回错误，install_pin 失败时撤掉码值并向 UI 报错；读到冲突状态按 fail-closed 保留保护。
直发文件批次使用 manual=true，切换目标/离线后仍继续发给旧设备。批量发送不再复用 manual 语义，逐文件检查当前 sendTargets 是否仍包含目标。
全局粘贴在昵称/搜索/配对码等任意输入框粘贴文件也会上传或直发。只有消息输入框接收文件粘贴，其余输入框阻止并提示。
发送失败时草稿已清空；用户若在等待期间继续输入，原消息永久丢失。失败时恢复原草稿；若用户已输入新内容则合并而非覆盖。
搜索/翻页后“删除选中”会删除当前看不见的文件。搜索、翻页、排序变化时清空选择；从聊天定位文件时先退出搜索。
App.vue 卸载时调用未定义的 stopIntroSpy()，抛错并中断 WS/轮询/监听清理。移除错误调用，清理顺序恢复；pet 异步监听/focus 逻辑一并补清理。
手机文件选择态点击行仍打开操作面板；16px 勾选框热区过小。选择态整行点击切换选择；勾选 label 扩为 28×44，文件 FILES tab 补新文件绿点。
“清空消息”清不掉远端文件卡片；失焦回来会把上翻历史时的新消息标已读。清空时同步清 remoteFiles；markChatSeen 仅贴底时推进已读水位。
移动端偏好目录与 save_text_pref_cmd 写路径不一致；Unix 在途键统一小写会误锁同名不同大小写文件。移动端统一走 server::ui_pref_dir；active_key 只在 Windows 折叠大小写。
诊断/日志导出同步写、非原子且可写敏感启动/密钥目录。改为异步 + 临时文件 fsync + rename；拒绝 .ssh/.gnupg/LaunchAgents/Startup 等路径。
