CC-Flash · 需求设计文档

文档日期：2026-10-26 状态：已实现，macOS 包已出 技术栈：Tauri 2 + Rust(axum) + Vue3

1项目背景与目标

同一 Wi-Fi 下的多台设备（手机 / 平板 / 电脑）之间经常需要快速互传文件、传一句话/一个链接。传统方案（微信文件传输助手、AirDrop、网盘）分别存在登录负担、生态限制、速度慢的问题。本项目提供一个零登录、零公网、开箱即用的局域网传输工具：

  • 电脑上启动服务，自动生成访问地址与二维码；
  • 手机 / 平板 / 电脑用浏览器扫码即可访问，无需安装任何 App；
  • 支持文件上传 / 下载 / 删除 / 分享，以及一个轻量聊天室。

1.1 技术形态

维度形态
技术栈Rust(axum) 局域网服务 + Vue3 前端 + Tauri 2 桌面壳
安装包体积dmg 5.9 MB / .app 13.5 MB（目标 5–12 MB ✅）
网页端与桌面端同一份 Vue 页面，按运行环境自适应：桌面侧栏三页 / 电脑浏览器双栏 / 手机单列+悬浮球
页面托管前端产物由服务端直接托管，手机扫码即用，无独立部署步骤

1.2 产品原则

  • 零配置：安装即用，端口/目录全自动，端口被占自动顺延；
  • 零学习成本：所有操作一目了然，文案口语化（"保姆级"标准）；
  • 可信赖的反馈：每个动作都有 toast 提示（上传/下载/复制/清空/错误），服务状态常驻可见（三圆点脉冲徽标）；
  • 低刺激视觉：全局深色主题，5 套可切换皮肤，颜色语义化（蓝=主操作、绿=成功/分享、红=危险）。

2用户角色与使用场景

角色入口典型诉求
服务发起者（电脑用户）Tauri 桌面窗口启停服务、改端口/共享目录、看谁在访问（日志）、生成二维码给别人、管理文件、参与聊天
访客（手机/平板/电脑浏览器）扫码或输入地址打开的网页快速上传照片/文档、下载需要的文件、拿到分享链接、临时聊天

2.1 核心场景

  1. 照片回传：手机拍的照片 → 浏览器上传 → 电脑立即取用；
  2. 资料分发：电脑把安装包/文档放进共享目录 → 同事扫码下载；
  3. 链接传递：电脑上复制的长链接 → 粘到聊天室 → 手机点开；
  4. 临时接力：开会时把会议纪要丢进聊天室，所有人立即可见可复制。
运行形态说明 桌面窗口关闭 = 收纳到系统托盘（服务不停，首次会发系统通知）；托盘菜单「退出」才是真正结束。

4文件共享模块

4.1 上传

  • 入口：拖拽区点击、拖放文件、粘贴事件（截图直接 Ctrl+V / Cmd+V）、多选；
  • 每项展示：文件名、状态（等待中 / 百分比+速率 / 完成 / 失败原因）、进度条；
  • 协议：POST /api/upload，文件名放请求头 X-Filename（URL 编码），声明大小放 X-File-Size；
  • 服务端先做磁盘空间预检：声明大小 > 可用空间 → 明确拒绝并写日志「上传拒绝」；
  • 流式落盘（1MB 分块），客户端中断/写盘失败自动删除半截文件并写日志。

4.2 下载与分享

  • 浏览器端：GET /api/download/:name，响应带 Content-Disposition attachment（RFC5987 支持中文）与 Content-Length（浏览器可显示进度）；
  • 分享：任何端点击「分享」= 复制下载链接到剪贴板，自动附加话术：
    固定话术（需求原文）「🔔 温馨提示：请在同一 Wi-Fi 下打开；文件请尽快下载到本地，共享文件不保证长期有效。」

4.3 操作按钮 · 平台差异（需求原文还原）

需求原文「在手机/电脑浏览器上共享文件展示的线性图标只需要有 下载、删除、分享 按钮；Tauri 桌面窗口展示的线性图标有：打开、复制、删除、分享 按钮。」
按钮桌面窗口浏览器行为
打开✅ 文件夹线性图标—（无文件系统能力）调用系统默认程序打开该文件
复制✅ 剪贴板线性图标—复制文件本体到系统剪贴板，可在访达/资源管理器直接粘贴（macOS 走 osascript，Windows 走 PowerShell）
下载—（桌面走「打开/复制」路径，需求不含此项）✅保存到本地；大文件（>1GB）自动转浏览器原生流式下载
删除✅✅弹确认框（防误删），支持批量
分享✅ 绿色，保持不改动✅ 绿色复制链接（见 4.2）

5聊天室模块

  • 收发：所有端 3 秒轮询一次；服务端保留最近 200 条；昵称截取前 20 字，消息截取前 2000 字；
  • 昵称：可手动输入并记忆；未设置时自动生成（如 Mac Chrome-2569：系统 + 浏览器 + 随机 4 位数，存 localStorage）；
  • 头像：昵称哈希 → 24 个 emoji 池映射，同昵称恒定同头像；
  • 未读：悬浮球角标显示未读数（99+ 封顶）；电脑端在聊天页时、手机面板打开时自动消红点；
  • 链接化：先 HTML 转义再匹配 URL 包裹为链接（防 XSS）；桌面窗口点击链接用系统浏览器打开；
  • 清空数据：仅清空本窗口显示，不影响服务端与他人；期间若又有新消息则自动恢复显示。

6服务控制模块

6.1 服务控制卡（自上而下）

  1. 状态区：运行徽标（三圆点波浪动效）+ 访问地址（等宽字体、点击全选、一键复制）+ 提示语「同一 Wi-Fi 下的设备用浏览器打开即可使用」；
  2. 配置区：端口（运行中锁定，被占用自动顺延）、共享目录（可换、悬停看全路径、「打开」按钮直达文件夹）、可用空间与「修改目录需重启服务生效」提示；
  3. 操作区：启动服务（蓝色主按钮）/ 停止服务（红色危险按钮）/ 打开共享目录；
  4. 二维码卡：白底大二维码（204px，贴边展示），未启动时显示虚线占位；caption「手机 / 平板同一 Wi-Fi 下扫码打开」。

6.2 IP 变化可靠性需求（FR-60）

服务绑定 0.0.0.0，DHCP 换 IP 不会中断服务，但客户端手里的旧地址会失联（表现为连接超时）。因此要求：

  • 前端每 2.5 秒刷新一次状态；检测到 IP 变化 → 地址栏/二维码/统计立即换新，并弹醒目提示「本机 IP 已变为 x.x.x.x，手机请改用新地址访问」；
  • 已打开的旧页面无法自救（旧 IP 已失联），必须以桌面端提示的新地址重开——这是本需求的边界。

7服务日志模块

  • 逐请求行：方法 路径 → 状态码 大小 耗时 ← 来源IP (昵称·设备)，设备由 UA 识别（iPhone/iPad/Android/微信内置/Mac/Windows/Linux），昵称取 X-Nickname 请求头；
  • 业务行：上传开始（含声明大小、是否覆盖同名、来源）/ 上传完成（大小+耗时）/ 上传失败·中断（含清理动作）/ 上传拒绝（空间不足）/ 下载（大小+来源）/ 下载失败 / 删除 / 删除失败 / 聊天（昵称+内容预览≤40字）/ 服务启停 / 端口顺延 / 目录文件数 / 日志已清空；
  • 时间：本地时间，精确到毫秒（chrono）；
  • 容量：环形缓冲 1000 条，超出淘汰最旧；
  • 豁免名单：聊天轮询、/api/info 状态轮询、日志拉取自身、favicon —— 不记录，防止刷屏；
  • 清空：按钮清空后写入一条「日志已清空」标记，便于确认生效。

8网页端（浏览器）模块

8.1 电脑浏览器布局

  1. 标题头部：应用 logo + 「CC-Flash / 局域网高速文件共享」；
  2. 顶部大卡：状态徽标 + 地址栏（HTTP 前缀 + 完整地址）+ 复制 + 二维码按钮；下方四格统计（本机 IP 蓝色 / 端口 / 文件数 / 总大小 白色），无边框分格；
  3. 内容区左右 1:1 双栏：左=上传拖拽卡 + 共享文件卡；右=聊天室卡（满高、输入框贴底、头部含清空数据按钮）。

8.2 手机浏览器布局（保持不变项）

  • 单列堆叠：顶部卡（地址行两行式：徽标+按钮一行，地址栏独占一行保证 IP 完整）→ 2×2 统计（每格独立描边小卡）→ 上传 → 文件（计数徽标在「共享文件」标题后）；
  • 聊天：右下角悬浮球（含未读角标）→ 底部面板（85vh），头部「聊天室标题 | 清空数据 | ✕」，第二行头像+昵称；
  • 关闭钮为 32px 圆形幽灵钮，常态中性灰、悬停泛红；面板打开锁定背景滚动。

10.3 图标规范

  • 全部使用 15–17px SVG 线性图标（feather 风格，stroke 2），不用 emoji 充当功能图标；
  • 线性图标按动作着色区分：下载=蓝、删除=红、分享=绿（分享按钮样式保持不改动）、打开/复制=中性灰；
  • 「打开浏览器」= 地球（globe）线性图标——语义是"浏览器"，不是外链箭头；
  • 文件行「复制」= 剪贴板图标（板子+夹子+内容行），与顶栏「复制链接」的双矩形明确区分。

13安全模型与边界

信任模型 可信局域网使用。控制台接口（启停/日志/清空）与文件接口均无鉴权——请只在可信 Wi-Fi 下使用，不要把端口暴露到公网。

13.1 内置防护

  • 路径穿越双重防护：URL 解码 → 取 basename（拒绝空/./..）→ 与共享目录拼接后 canonicalize 校验前缀越界；
  • XSS 防护：聊天消息先转义再链接化；
  • 资源上限：聊天 200 条 / 昵称 20 字 / 消息 2000 字 / 日志 1000 条；
  • 删除确认：所有删除必须经确认框。

15验收标准（摘要）

  1. 安装 dmg 后双击即用，无依赖安装；关窗后手机仍可访问（托盘常驻）；
  2. 手机扫码 3 秒内打开可用页面；上传 100MB 文件有实时进度，完成后桌面列表自动出现；
  3. 桌面端四个按钮、浏览器三个按钮与需求矩阵完全一致，点击均有响应与反馈；
  4. 分享在桌面端/电脑浏览器/手机上均为复制链接且自带话术；
  5. 改 Wi-Fi（换 IP）后 5 秒内桌面端弹出提示且二维码已更新；
  6. 日志含每次上传/下载/删除/聊天的明细与来源，清空后有标记线；
  7. 5 套皮肤切换即时生效；窄屏（375px 宽）下地址完整、聊天面板无滚动穿透；
  8. 侧边栏「介绍」可打开全屏介绍页，锚点导航高亮跟随滚动，Esc 关闭；关窗后左键托盘图标 / 程序坞图标可唤回主窗口，运行中重复启动不再产生新托盘图标。
