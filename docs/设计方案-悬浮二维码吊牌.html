交互与视觉说明（本页演示）

  • 全局常驻：所有桌面页面可见，无需切换到服务中心（演示中仅服务运行且二维码生成后出现）。
  • 注意力平衡：±1.15° 缓慢摇摆 + 2.2s 上下流光扫描；低饱和蓝光，简洁不刺眼（本页专属视觉，最终实现改用呼吸环）。
  • 拖拽交互：Pointer Capture 跟手，5px 死区区分点击；位置夹紧到视口并持久记忆。
  • 控制方式：“—” 隐藏为右下迷你码，可恢复；“✕” 关闭；服务停止自动消失（演示交互，最终实现无此两按钮）。
  • 平台范围：在电脑桌面界面展示，窄窗口同样支持；CC 设置可控制开关；手机浏览器不展示。
  • 可访问性：系统开启减弱动态效果时停用摇摆和流光；按钮带 ARIA 标签。

与最终实现的对照

  • 形态：最终实现为贴边收拢的呼吸圆点（窗口中心压屏幕边缘线、圆点漏一半在屏内），珊瑚呼吸环 + 取景框 CC 徽章，而非本页的悬挂吊牌卡片；
  • 尺寸与命中区：收拢窗口 96×96（64px 呼吸圆点 + 四周 16px 透明缓冲），展开 136×190；在场判定以 250ms 光标轮询（cursorPosition() 与窗口 outer 矩形求交）为权威通道，mouseenter/leave 仅作加速——窗口被程序化移动/页面重载后 WebKit 会丢失边界事件配对；
  • 出码方式：指针停留 1.5 秒滑出 136×190「浏览器扫一扫」预览卡、离开 250ms 收拢（点击圆点或预览卡等效打开主窗口），而非点击放大弹窗；
  • 拖动：松手自动吸附最近边（在哪块屏就吸哪块屏，支持扩展屏），位置连同显示器持久记忆（pet-dock.json 记显示器锚），重启回原屏原位；Windows 混合 DPI（主屏/扩展屏缩放不同）下按目标屏缩放换算物理坐标，不会落错位或被自愈巡检反复搬回主屏；
  • 显示时机：首次落位完成（或 2.5s 兜底）后才显示，主窗状态轮询的强制重显需等 pet_ready_cmd 上报，避免在 Rust 默认位（主屏左缘）闪现；展开落位期间离开也会排收起，不会卡在展开态；关闭开关后 Pet 窗停止轮询；
  • 控制：圆点上没有 ✕ / 隐藏按钮，唯一关闭入口是 CC设置「悬浮二维码」开关；服务停止不消失——外圈呼吸静止 + 暗底空态面板表达停止态；
  • 提醒：外圈绿点提示新文件 / 新消息（与呼吸环同组、同相位缩放，按吸附边旋到可见半侧，主窗打开自动隐藏并清零）。
  • 主题：悬浮码强调色跟随当前配色；应用共 5 套配色 × 亮/暗/跟随（深空蓝 / 石墨玫瑰 / 森林薄荷 / 暗夜紫 / 墨色琥珀），不再包含早期演示中的微信绿。

  • 桌面侧栏 192px，不再有独立「周边设备」入口；设备栏并入「消息发送」页左侧（200px，本机共享 + 附近设备 + 刷新）。
