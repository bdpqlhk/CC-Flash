CC Flash · 2026-11-23 实时同步与全端校准

版本：v1.2.6+ · 本文件记录本轮全量复审后的修复与验证；与《技术实现文档》《需求设计文档》《保姆级使用说明》配套阅读。
本轮重点设备在线态改为服务端权威 + WebSocket 实时同步；发送面板跟随皮肤；移动设置页按 dir-3 设计稿收口；悬浮窗透明背景、昵称弹框点击、配对取消按钮和附近设备收藏/历史入口修复；同时补齐发布与安全边界。

一、设备发现与在线态

问题修复
两台设备频繁在在线/离线切换：前端 6s 阈值、后端 15s TTL，3s 轮询/多播丢包就会跳变。后端 TTL 30s，服务端按 12s 宽限计算 online；前端直接使用服务端字段，不再用浏览器时钟猜状态。
WS 在线时事件触发的加载失败无重试，时间线/文件列表可能长期停在旧数据。聊天/文件加载失败安排 2s 补拉；WS 仍保留 3s 轮询兜底。
多播/广播被 Android/企业 Wi-Fi 单向过滤，首次发现后心跳断。已知 peer 每 3s 单播 announce；每 5s 单播 probe 兼容旧版本；子网 /24 扫描改为仅用户显式「扫描」触发。
每条 UDP 报文都广播完整设备列表，存在放大风险。仅新增/字段变化立即推 devices:presence；普通心跳合并为 3s 周期全量 presence。
设备列表在设备静默后仍显示 online。3s 周期 presence 重算 online，12s 无心跳准时变离线，30s 才移除。

二、发送面板、设置与设备卡片

问题修复
发送面板固定墨绿，和当前皮肤不一致。面板所有颜色改用主题 token：背景、边框、Tab、拖拽区、文件图标、发送按钮；信号台/玫瑰/薄荷/亮色均已验证。
手机设置页卡片多、说明长。按 design-demos/cc-flash-app/dir-3.html 改为扁平行：令牌、剪贴板、重启、外观、版本行；开关文案精简，外观保留配色芯片与亮/暗/跟随系统。
附近设备只有星标，操作入口不清晰。设备卡右侧独立动作栏：右上收藏、右下传输历史；主体选择按钮与动作分离，避免嵌套按钮。
配对码弹框取消按钮贴左、视觉过重。改为居中的轻量文字按钮；toast 空容器设为 pointer-events:none 且弹框时 bottom:auto，避免整屏透明层吞点击。
悬浮二维码底部黑块。主题 body 背景覆盖了 Pet 透明规则；在样式末尾强制透明，并给 Pet WebView 设置 alpha=0 背景。
桌面主区在窗口切后台/未聚焦时整块空白，只剩侧栏。移除 .main > * 的 opacity 淡入动画；WKWebView 在窗口不可见时会暂停动画，停在 opacity:0。主内容现在始终可见，不再依赖动画首帧。
手机浏览器（vivo 等）顶部出现整条空白，输入框占位文字换行。仅在可视高度缩小（键盘）时使用 visualViewport.offsetTop；普通 Android 浏览器标记 data-android-browser，页头不再叠加 env(safe-area-inset-top)，地址栏/状态栏不会形成整条空白；移动浏览器占位文案缩短为「说点什么…」。

三、安全与发布

问题修复
开启/轮换 PIN 后旧 WS 仍订阅事件。set_access_pin_cmd 调用 ws_kick，旧连接重新认证。
移动端开启令牌后本机请求先 401。toggleAccessPin 成功后立即把返回 PIN 写入 accessPin，媒体/列表刷新不再弹配对框。
对端 PIN 以 ip:port 记忆，地址复用可能把 PIN 发给冒名设备。改为稳定设备 id 键，地址/端口变化不会命中旧 PIN。
聊天/探测 body 在限流前缓冲，存在内存耗尽风险。chat body 上限 256KB、probe 4KB；新增全局 body 许可（32），先于 handler 限制并发。
一次性票据可借 Range 重放；bytes=0- 可整包重复。RecentTicket 取原始票据过期时间上限，拒绝已消费票据的 bytes=0- 整包 Range。
同 IP 随机新 id 可驱逐真实设备。同 IP 已有未过期 id 时拒绝新 id，旧条目 30s TTL 后再登记。
资产只按扩展名检查；密钥守卫漏加密 PEM。精确校验四个资产名；私钥守卫补加密 PEM 与 .p8/.key/.cer/.der/.pfx/.pem；design-demos/ 加入忽略。缺签名 Secrets 时维持既定策略：只打 ::warning:: 并继续发布未签名/未公证包，Release 说明中注明 macOS 右键打开、Windows SmartScreen 提示。
API 兜底生成提交与本地 refs 分叉。api-push.sh 增加祖先/fast-forward 校验；后续发版前仍需按脚本提示同步本地 refs。
