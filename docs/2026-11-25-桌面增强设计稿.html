01 / FILE SEARCH
文件多之后的刚需

文件列表搜索

纯前端过滤，桌面抽屉、手机文件页和浏览器共享页共用；输入即筛选，清空即恢复。

01 文件页已落地

搜索文件名或上传者 不改变排序，不发请求

搜索框放在文件列表上方。匹配文件名与上传者，忽略大小写；批量选择时，已选集合不会因为筛选而丢失。

  • 即时：输入即过滤，清空即回到完整列表；不触发服务器往返。
  • 计数：显示「匹配 N / 共 M」，没有结果时给出清除搜索入口。
  • 不打断选择：筛选只影响可见行；隐藏项仍然被选中，底部操作沿用原语义。
  • 移动端：输入框 16px，避免 iOS 聚焦放大整页。
验收搜索 report 只留下 report 相关行；清空恢复；批量选择不丢失；320px 无横向溢出。
02 / SHORTCUTS
托盘与悬浮球

把地址和文件夹放到手边

两个系统级入口，只做「复制访问地址」和「打开共享文件夹」。主窗口的完整右键菜单保留，不混用。

02 托盘菜单已落地

复制访问地址 少开一次主窗口

托盘菜单新增「复制访问地址」，剪贴板得到可直接粘贴到浏览器的完整 URL；服务未启动时不复制过期地址。

  • 内容：http://IP:端口，带协议；界面文案仍可读作「IP:端口」。
  • 反馈：主窗口不可见时用系统通知确认；悬浮球可见时球边显示「已复制」。
  • 不打扰：不打开主窗口，不弹面板，不改变服务状态。
验收托盘点击后剪贴板为完整 URL；服务停止时不复制；主窗口保持隐藏。
03 悬浮球右键已落地

只保留两个动作 不是第二个设置页

旧版右键会弹出复制页面、手动发送、重新扫描、设备诊断四项，属于主窗口的能力，不该从一颗小悬浮球上弹出。新版只保留打开共享文件夹与复制访问地址。

  • 范围：仅 pet 悬浮球；主窗口右键菜单保持不变。
  • 状态：服务停止时复制项禁用；打开文件夹仍可用。
  • 关闭：点击空白、Esc、切换窗口都关闭，不阻塞悬停扫码卡。
验收右键只出现两项；旧四项不再出现；主窗口菜单不受影响。

03 / DRAG
最短的上传路径

拖到球上，松手即上传

不切换窗口、不选目标、不打开面板。拖入文件时球边出现提示，上传中显示进度环，完成后短暂显示对勾。

04 悬浮球拖拽已落地

文件落到球上 只进本机共享

支持文件，不支持文件夹；默认写入本机共享目录，不绑定当前选中设备，避免误发给陌生设备。完成后主窗与手机端文件列表立即刷新。

  • 视觉：拖入时虚线环 +「松手到本机共享」；传输中 0–99% 进度环；完成显示对勾 1.8 秒。
  • 安全：只读取用户主动拖入的文件；文件名走既有净化规则；同名自动顺延。
  • 失败：服务未启动、磁盘不足、文件夹拖入时显示红色短提示，不静默。
  • 不改：左键点击仍打开主窗口；拖拽与点击手势互不抢占。
验收拖入 1 个文件后共享列表出现；拖入文件夹给出明确提示；上传中可见进度；完成/失败都不静默。
04 / SUPPORT
让报障变成一条附件

诊断包与日志导出

不要求用户理解日志结构。设置页一键生成诊断 ZIP；日志页直接导出原始 .log，适合工单与聊天窗口。

05 诊断包已落地

把上下文一次带走 默认脱敏

诊断包包含版本、系统、脱敏配置、最近日志与 pref-pet-dbg-* 诊断文件；不包含聊天内容、文件名或访问令牌。

  • 内容：meta.json / config.json / logs.txt / prefs/* / manifest.txt。
  • 脱敏：配置不含 PIN/令牌；局域网 IP 只保留网段；不打包聊天与文件列表。
  • 保存：系统保存对话框选择路径；生成 ZIP 不阻塞主界面。
  • 反馈：成功后提示文件大小；失败说明写入原因。
验收ZIP 可正常解压；包含诊断文件；无 PIN/聊天；文件名带日期。
06 日志导出已落地

保留原始文本 不被筛选结果影响

日志页增加「导出日志」。导出当前完整日志，而不是屏幕上的筛选结果；保留时间戳、级别、位置和消息原文。

  • 范围：默认导出全部；有筛选时按钮旁提示「导出完整日志」。
  • 格式：UTF-8 纯文本，保留原始结构；不改写、不折叠。
  • 保存：系统保存对话框；文件名带日期；失败有提示。
验收导出文件可被文本编辑器打开；筛选状态下仍为全量；日志为空时给出提示。
