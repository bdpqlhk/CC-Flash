快速开始

三步，把内容交给对方。

无需注册、无需配置网络、无需数据线。装好打开就能用。

STEP 01

电脑启动服务

打开 CC-Flash，服务自动启动。窗口右上角显示「● 运行中」和一行地址（默认 http://电脑IP:1688，端口被占用会自动顺延）。

STEP 02

手机扫码或输地址

手机连同一个 Wi-Fi，用相机扫二维码，或直接在浏览器输入窗口里的地址。Android 也可以安装 APK 使用。

STEP 03

开始互传

拖文件、点上传、发消息都行。文件会以卡片出现在对话里，完整共享文件收在「共享文件」抽屉 / 面板里。

一句话记住：电脑是驿站，浏览器是取件码，地址 + 端口就是一切。手机和电脑必须在同一个 Wi-Fi / 同一个路由器下。

桌面端

电脑上的完整操作台。

macOS 11+ / Windows；Linux 可从源码构建。以下操作在桌面壳内完成。

1安装与首次打开

  • macOS：Apple Silicon 选 _aarch64.dmg，Intel 选 _x64.dmg，拖入「应用程序」。首次若提示无法验证开发者，右键 →「打开」→ 再点「打开」；或到「系统设置 → 隐私与安全性」点「仍要打开」。
  • Windows：运行 .exe（NSIS 安装包）。若 SmartScreen 提示「已保护你的电脑」，点「更多信息」→「仍要运行」。首次启动允许专用网络防火墙授权，否则手机连不上。
  • Linux：npm install && npm run tauri build 从源码构建。

2上传文件的 5 种方式

  1. ＋ 面板：点输入栏左侧「＋」→「文件」，可多选。
  2. 拖拽：把文件或整个文件夹从访达 / 资源管理器拖到页面任意位置，松手即传（保持目录结构）。
  3. 选择文件夹：「＋」→「文件夹」；iOS Safari 不支持选文件夹，入口会自动隐藏。
  4. 粘贴：截图后直接 Cmd/Ctrl + V。
  5. 手机上传：手机打开页面点「＋」上传。

上传为单请求整文件直传，流式落盘、零内存占用；同名文件永不覆盖，自动顺延为 报告(1).zip；中断的半截文件会被服务端即时清理，Windows 句柄占用时会保留标记等下次启动清理。

5消息、昵称与未读

  • 同一 Wi-Fi 下打开页面的人都在同一间「消息发送」房间，消息 WebSocket 实时推送，断线自动降级为约 3 秒轮询兜底。
  • 改昵称：点房间头右侧头像，保存后立即生效；不改会按设备自动起名（如「Mac Chrome-2569」）。
  • Markdown：标题、列表、引用、分割线、代码块、行内代码、粗体、斜体、删除线、[文字](链接) 与裸链接。
  • 多行输入：桌面 Enter 发送、Shift+Enter 换行；手机 Enter 换行、点发送提交。中文输入法组字时不会误发。
  • 未读：页面在前台且窗口有焦点时自动已读；上翻历史时底部浮出「N 条新消息 · 回到底部」。
  • 聊天记录服务端保留最近 200 条（总量 200 万字符预算，持久化到本地，重启恢复）；「清空消息」只清本窗口显示。单条消息最多 200000 字符，输入栏实时显示字数，超限会提示并禁止发送。

6服务中心与 CC设置

服务中心

启停服务、端口（默认 1688，被占自动顺延）、共享目录（打开 / 选择；运行中切换会自动「停止 → 切换 → 重启」）、磁盘可用空间、loguru 风格实时日志（INFO / SUCCESS / WARNING / ERROR 着色，来源 文件:行号）。

CC设置

开机自动启动（默认关闭）、访问令牌、悬浮二维码、皮肤（亮 / 暗 / 跟随系统 × 六套配色，默认信号台）、检查更新。移动 App 还多出「重启服务 / 访问令牌 / 剪贴板同步」。

7悬浮二维码与托盘

  • 悬浮码：贴边呼吸球默认在左侧中部，鼠标停 1.5 秒滑出扫码卡；按住可拖到任意边缘并自动吸附，支持扩展屏与 Windows 混合 DPI；外圈呼吸 = 运行中、静止 = 已停止，绿点 = 有新文件 / 新消息；开关在「CC设置 → 悬浮二维码」。
  • 关窗 ≠ 退出：点关闭按钮收进系统托盘，服务继续运行；左键托盘图标唤出主窗，右键菜单可启停服务、打开网页或退出。
  • 单实例：重复双击只会唤起已有窗口，不会堆积托盘图标。
手机端

浏览器免安装，App 更完整。

手机浏览器扫码即用；Android App 是独立本机节点。

手机浏览器（免安装）

  • 相机扫码，或输入 http://电脑IP:端口。
  • 顶部：房间名 / 清空消息 / 文件夹（共享文件数）/ ⋯ 更多。
  • 上传：＋ → 文件 / 文件夹 / 粘贴；下载：文件卡片「下载」或共享面板「⋯ → 下载」。
  • ≤50MB 走内存 blob（有完成提示），更大的交浏览器原生流式下载。
  • 微信内置浏览器会提示点右上角 ⋯ → 在浏览器打开，否则下载可能被拦截。
  • HTTP 局域网地址下浏览器不支持 PWA 离线安装，只能「添加到主屏幕」创建快捷方式。

Android App（推荐）

  • Releases 只提供一个 arm64-v8a APK，覆盖 Android 7.0+（minSdk 24）主流 64 位机型。
  • 默认独立节点：手机本机运行文件服务与聊天，只监听 127.0.0.1（安全模式），其他设备访问不到。
  • 手机共享目录始终开放局域网，并自动生成本机访问令牌；同网段设备需输入配对码。
  • 要浏览电脑文件：直接用手机浏览器打开电脑地址；App 本身作为独立节点运行。
  • Android 用前台服务通知保活；附近设备发现会持有 MulticastLock。

8附近设备怎么用

  • 同一 Wi-Fi 下运行 CC-Flash 的电脑 / 手机 App 会自动出现在顶部「附近设备」条，显示在线 / 忙碌状态。
  • 点设备 → 输入消息或选择文件 → 发送。内容会投递到对方的公共聊天与共享目录，同网段设备可见，请勿发送敏感内容。
  • 纯浏览器页面没有自己的监听端口，不会出现在可发送列表里，避免「点得到、连不上」。
  • 星标可收藏常用设备并置顶。

安全须知

传得快，也要传得安心。

面向可信局域网设计；半可信网络请开启访问令牌，移动端默认只监听本机。

数据不出局域网不上云、无账号体系、不经过任何第三方服务器。拔掉外网，功能照常。上传 / 下载 / WebSocket 分别有 16 / 32 / 64 并发闸，停服时在途上传会回滚半截文件。
访问令牌（可选）6 位配对码走请求头，本机免输；连续输错按来源 IP 指数退避，IPv6 再按 /64 聚合，公网来源还有全局失败预算。分享链接为一次性票据，绑定文件大小 / ETag，10 分钟有效，删除或同名重传后立即失效。
请勿在公共 Wi-Fi 裸奔默认同一网络的任何人都能查看 / 下载 / 删除共享文件、发言。公共或半可信网络请开启访问令牌；手机 App 始终开放局域网并自动生成本机访问令牌。
VPN / 远程组网视为局域网10/8、172.16/12、192.168/16、100.64/10（运营商 NAT / Tailscale）与 IPv6 ULA / link-local 都按私网处理。连着公司 VPN 或共享 Tailscale 网络时，请确认网段内其他主机可信。
控制接口只限本机启停服务、清空日志等接口仅回环可访问，并拒绝跨站简单请求；静态页面补了防点击劫持与 MIME 嗅探头。Windows 首次监听时请允许「专用网络」，否则手机连不上。
重要文件及时取走默认共享目录是 ~/CC-Flash；卸载软件前先把需要的文件取走。删除不可撤销，分享链接也会随文件删除立即失效。
常见问题

开始之前，了解这些。

点开每一条查看答案；更多细节见文末的完整文档。

手机打开地址一直转圈 / 提示连接超时？+
① 确认手机和电脑连的是同一个 Wi-Fi；② 电脑换过网络后 IP 会变，看桌面端提示的新地址；③ 在电脑浏览器打开该地址自检；④ 公司网络可能开了 AP 隔离，换个热点试；⑤ Windows 首次启动时若拒绝了防火墙授权，到「Windows Defender 防火墙 → 允许应用通过」勾选 CC-Flash 的「专用网络」。
窗口点了 ×，手机还能用吗？+
能。关窗只是把窗口收进系统托盘，服务继续运行，手机照样访问。彻底退出请用托盘菜单里的「退出」。
启动提示端口被占用怎么办？+
无需处理：会自动顺延到下一个可用端口，地址栏里的端口号同步变化。也可以停止服务后手动指定端口再启动。
上传到一半断了，文件会坏吗？+
不会。中断的半截文件会被服务端即时清理（少数 Windows 句柄占用场景会保留上传标记，下次启动再清理），目录里不会出现可下载的残缺文件；重新上传即为完整重传。上传期间手机屏幕会自动保持常亮。
上传的文件和目录里已有文件重名？+
不会被覆盖：自动改名为 xxx(1).zip、(2)、(3) 依次顺延，原文件保留；完成后会提示实际保存的名字。
访问令牌、分享链接安全吗？+
访问令牌是 6 位配对码，本机免输；连续输错按来源 IP 指数退避，公网来源还有全局失败预算。开启后分享按钮生成的链接只授权下载那一个文件、10 分钟有效、完整下载一次即失效，且绑定文件大小 / ETag —— 文件被删除或同名重传后旧链接立即失效。关闭令牌或切换共享目录时所有未使用链接同步作废。
电脑换了 IP 或换了另一台电脑？+
手机浏览器直接打开电脑端显示的新地址即可。Android App 是独立本机节点，电脑换 IP 不影响手机；本机服务异常时点「重新启动本机服务」。浏览器地址只支持 IP / localhost（xxx.local 会被拒绝，防 DNS 重绑定）。
Android 手机怎么装？装完为什么看不到电脑文件？+
到 Releases 按 CPU 选 APK（多数手机用 arm64-v8a），允许「未知来源」安装。App 是独立本机节点，始终开放局域网并自动生成本机访问令牌；看不到电脑文件属正常，用手机浏览器打开电脑地址即可。
「附近设备」里为什么没有某台设备？+
附近设备只显示运行 CC-Flash 的电脑 / 手机 App（通过 IPv4 UDP 多播 239.255.42.99:53318 + 广播发现）；纯浏览器页面没有监听端口，不会出现。确认双方在同一 Wi-Fi、都开启了服务；手机 App 始终开放局域网并广播，同网段设备需配对码；Windows 还需在防火墙放行 UDP 53318。部分 Android 网络会过滤多播，广播兜底可能需要几秒。注意：纯浏览器页面向另一台设备投递时，目标设备未开启访问令牌则只允许发消息/文件（读取、删除、生成分享票据会被拒绝）；桌面 / 手机 App 客户端不受此限制；对方开启访问令牌时，在投递弹窗里填写对方配对码即可（会按设备记住）。
macOS 提示「已损坏，无法打开」/ Windows 提示 SmartScreen？+
安装包未做付费代码签名，属正常现象。macOS：右键 →「打开」→「打开」，或到「系统设置 → 隐私与安全性」点「仍要打开」；仍不行可在终端执行 xattr -dr com.apple.quarantine /Applications/CC-Flash.app。Windows：点「更多信息」→「仍要运行」。请只从官方 Releases 下载。
屏幕边缘的呼吸小球不见了 / 想关掉？+
开关在「CC设置 → 悬浮二维码」（唯一关闭入口），关闭后立即消失且重启保持；重新打开会恢复上次拖到的位置。鼠标停 1.5 秒出码，按住可拖到任意边缘，支持扩展屏与 Windows 混合 DPI。
手机浏览器能「安装」成应用吗？+
通过 https 或 localhost 访问时可以安装为 PWA 并离线缓存壳；通过 http://局域网IP 访问时浏览器不提供安装能力，只能「添加到主屏幕」创建快捷方式（不缓存离线）。桌面端与 Android 建议直接用原生安装包。
