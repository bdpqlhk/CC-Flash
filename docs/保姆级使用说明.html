👋 CC-Flash · 保姆级使用说明

局域网高速文件互传 · 电脑开机当服务器，手机扫码就能传 · 2026-10-26

1这是什么软件？

一个装在电脑上的「局域网文件驿站」：电脑启动服务后，同一 Wi-Fi 下的手机、平板、其他电脑用浏览器扫码，就能互相传文件、发消息——不用登录、不用数据线、不用装 App、不走外网（速度就是你路由器的速度）。

你能做什么举例
📷 手机照片回传电脑拍完照扫码上传，电脑立刻拿到原图
📄 电脑资料分发安装包、文档丢进共享目录，同事扫码自取
🔗 链接/文字接力电脑上的长链接发到聊天室，手机一点就开
💬 临时群聊开会时所有人扫码进聊天室，纪要即发即见
使用前提（很重要）手机和电脑必须连的是同一个 Wi-Fi / 同一个路由器。公司访客网络与办公内网隔离时互访不通。
第一次用先看介绍页侧边栏品牌旁的「ⓘ 介绍」按钮会打开全屏软件介绍页：功能一览、三步上手、技术实现与常见问题，顶栏可锚点跳转。看完点右上角 ✕ 或按 Esc 关闭。

2安装（macOS）

1
拿到安装包（如 CC-Flash_aarch64.dmg，版本号见文件名），双击打开。
2
把 CC-Flash 拖入「应用程序」文件夹。
3
首次打开若提示「无法验证开发者」：在启动台右键点它 → 打开 → 再点「打开」即可（仅第一次需要）。

Windows 版（.msi/.exe）将在 Windows 平台验证后提供。

3三步上手（最快路径）

1
打开软件 —— 服务自动启动。窗口顶部出现绿色的「● 运行中」徽标和一行地址（如 http://192.168.1.8:1688）。三颗跳动的小圆点 = 服务活着。
2
手机扫码 —— 点顶栏的二维码按钮 ▦，用手机相机扫码；或直接在手机浏览器输入窗口里那行地址。
3
开始传 —— 手机页面点上传选照片，电脑的「共享文件」列表立刻出现；反过来电脑点文件行的分享按钮，把链接发给手机也能下载。
一句话记住电脑是驿站，浏览器是取件码：地址+端口就是一切。

4桌面端 · 文件共享页

4.1 上传文件的 5 种方式

  1. 点击上传区 → 弹出选文件窗口（可多选）；
  2. 拖拽 → 把文件、或整个文件夹从访达拖到虚线框里（文件夹会保持目录结构）；
  3. 选择文件夹 → 上传区里的蓝色「选择文件夹」链接，整个文件夹一次上传；
  4. 粘贴 → 截图后直接 Ctrl+V / Cmd+V（微信截图、系统截图都行）；
  5. 手机上传 → 手机打开页面点上传（见第 7 节）。

上传时会显示进度条 + 百分比 + 实时速率；完成显示「完成」。没有大小和类型限制。大文件传到一半断网、手机锁屏也不用重来——恢复后自动从断点继续。

4.2 认识文件列表

元素说明
彩色小徽标（FILE/PDF/VID/ZIP…）文件类型一眼识别；图片会直接显示缩略图，并带黄色「预览」
文件名 / 大小 / 时间时间是相对的（刚刚、5 分钟前…）；点文件名可复制分享链接
排序按钮 最新 | 名称 | 大小切换列表排序方式
「N 个文件」（标题旁徽标）当前共享文件总数
↻ 刷新手动刷新列表，加载时按钮会转圈；平时自动同步（推送即时更新，断开时每 5 秒兜底刷新）——手机上传的文件桌面会立刻出现，一般不用手动点（快捷键 F5）
复选框「全选」勾选后出现「🗑 删除选中」批量按钮
页码 ‹ 1 2 … ›每页 8 条，文件多时翻页

4.3 每个操作按钮（悬停有文字提示）

按钮作用点完会发生什么
📂 打开用系统默认程序打开这个文件立即打开（如图片进预览、文档进办公软件）
📋 复制把文件本体复制到剪贴板去访达/资源管理器 Cmd+V 直接粘贴出文件
🗑 删除删除该文件弹确认框，确认后列表移除（不可撤销）
🔗 分享复制该文件的下载链接提示「分享链接已复制」，链接自带温馨提示话术，发给同一 Wi-Fi 的朋友即可下载
为什么桌面没有「下载」按钮？电脑上你可以直接「打开」或「复制」拿文件，不必经过浏览器下载；「下载」只出现在手机/浏览器端。这是刻意设计。

5桌面端 · 聊天室

  • 左侧导航点「💬 聊天室」进入；所有打开页面的人（含手机）在同一间聊天室，约 3 秒同步一次；
  • 改昵称：右上角「昵称:」输入框，回车即保存并记住；不改就自动叫「Mac Chrome-2569」这样的名字；
  • 头像：根据昵称自动分配一个 emoji，同昵称永远同头像；
  • 发链接：直接粘贴网址发送，会变成可点击的蓝色链接（电脑点开走系统浏览器）；
  • 清空数据：只清掉自己窗口里的显示，别人的和服务端的记录都在；之后只要有新消息就会恢复显示；
  • 聊天记录服务端保留最近 200 条，重启服务后清空（定位是临时接力，不做存档）。

6桌面端 · 服务与日志页

6.1 服务控制

控件怎么用
「● ● 运行中」徽标三颗跳动小圆点 = 服务健康；灰色「○ 已停止」= 未启动
地址行点击地址全选，→ 复制按钮一键复制；下方提示「同一 Wi-Fi 下的设备用浏览器打开即可使用」
端口默认 1688；运行中锁定；被别的程序占用会自动顺延到下一个可用端口
共享目录所有传的文件都存在这个文件夹；点「打开」直达，或点「选择」弹出系统目录框直接选取（选定即保存）；换目录后需停止→启动才生效
💾 可用空间所在磁盘的剩余/总容量；空间不足时上传会被拒绝并提示
启动服务 停止服务 打开共享目录三个主操作按钮

6.2 手机扫码直达

白底大二维码，手机相机直接扫；未启动服务时显示占位框。若电脑换了网络（IP 变了），地址和二维码会在 5 秒内自动更新，并弹提示「本机 IP 已变为 …，手机请改用新地址访问」——这时让手机重新扫一次即可。

6.3 服务日志

  • 谁在上传、谁在下载、谁发了什么、何时启停，全部带时间（精确到 0.001 秒）和来源 IP / 设备名；
  • 例：[16:12:14.114] 上传完成 照片.jpg (3.2 MB, 820ms) ← 10.161.1.5；
  • 普通刷新类动作（页面轮询）不会刷屏，请放心看；
  • 「清空日志」按钮：一键清屏，会留一条「日志已清空」标记。

6.4 皮肤设置

五套深色主题：深空蓝 / 石墨灰 / 极光蓝 / 护眼暖黑 / 暗夜紫。点色块立即换色并记住选择，手机端页面同步换色。「护眼暖黑」适合夜间长时间使用。

6.5 版本与更新

  • 「关于」卡显示当前版本，点「检查更新」会去 GitHub 查询最新版本（需要电脑能访问 GitHub）；
  • 有新版本会弹框对比当前/最新版本和更新说明，点「前往下载」直接打开下载页；
  • 平时不用管：软件每天最多自动静默检查一次，有新版才提醒；
  • 页面底部有版权页脚 © 2026-现在 by hangkun.li。

7手机端使用全攻略

7.1 打开页面

相机扫桌面上的二维码 → 自动用浏览器打开。可以把页面「添加到主屏幕」当 App 用。

7.2 页面长什么样

  • 顶部：运行状态徽标 + 地址栏（点一下全选）+ 复制/二维码按钮；下面是四格小卡（本机 IP、端口、文件数、总大小）；
  • 如果服务停了或电脑地址变了，约 5 秒后整个页面会变成「无信号」测试卡画面（电视没信号那种），并提示去电脑端查看最新地址——重新打开即可；
  • 中部：上传区 + 共享文件列表；
  • 右下角：💬 悬浮球——聊天入口，有新消息会显示红色未读数。

7.3 传文件

  • 上传：点上传区 → 选照片/文件（可多选，也能现场拍照）；
  • 下载：文件行的蓝色下载按钮，完成后有「已下载」提示；大文件（>1GB）自动转为浏览器直接下载；
  • 删除：红色按钮（有确认框）；
  • 分享：绿色按钮 → 复制该文件的下载链接（自带温馨提示），粘贴发给朋友即可。

7.4 聊天面板

  • 点悬浮球从底部滑出聊天面板；顶部一排是：标题、清空数据、圆形 ✕（悬停变红）；下面是头像和昵称；
  • 拖动顶部小横条或点蒙层都能收起面板；面板打开时背后页面不会跟着乱滑；
  • 有未读消息时悬浮球显示红色数字角标，打开面板自动清零。

8托盘与退出

  • 点窗口红色关闭按钮 ≠ 退出：窗口收纳到系统托盘（菜单栏右上角图标），服务继续运行，手机照样能访问；首次收纳会弹系统通知提醒你；
  • 左键点托盘图标：直接唤出主窗口；右键打开菜单：显示主窗口 / 启动·停止服务 / 打开网页 / 退出。macOS 也可以点程序坞里的图标重新打开窗口；
  • 单实例守卫：应用已在运行时再次双击图标（桌面 / 开始菜单 / 程序坞），不会再开一个新窗口、也不会多出托盘图标，只会把已有主窗口唤到前台；
  • 开机自启（可选）：「CC设置」→ 打开「开机自动启动」（默认关闭，打开开关才注册）。开启后登录电脑时服务在后台自动启动、不弹出主窗口，点托盘或应用图标随时唤出。请从「应用程序」目录里的正式安装版开启——若从 DMG 或开发目录运行，登录自启会指向临时路径而失效；
  • 想彻底关掉：托盘菜单 →「退出」。

9皮肤与外观

「服务与日志」页底部 → 皮肤设置：五套主题即点即换、自动记忆，桌面和手机页面一起换色。夜间推荐「护眼暖黑」。

10常见问题 FAQ

Q1：手机打开地址一直转圈 / 提示连接超时（TimedOut）？
① 确认手机和电脑连的是同一个 Wi-Fi；② 电脑如果换过网络，IP 会变——看桌面端提示的新地址，手机改用新地址；③ 试着 ping 或直接在电脑浏览器里打开该地址自检；④ 公司网络可能开了「AP 隔离」，换个热点试。
Q2：窗口右上角 × 了，手机还能用吗？
能。关窗只是收进托盘，服务还在跑；彻底退出请用托盘菜单的「退出」。
Q3：启动时提示端口被占用？
会自动换到下一个可用端口（地址栏里的端口号会变），无需处理。也可停止服务后手动改端口再启动。
Q4：上传失败提示「磁盘空间不足」？
共享目录所在磁盘满了。清理空间，或把共享目录换到别的盘（改完需重启服务）。
Q5：上传到一半断了，文件会坏吗？
不会。断点会被保留，恢复后自动从断处继续传（页面关了重开、重选同一个文件也认得进度）；电脑重启后断点清空，重传即可。
Q6：手机上下载大文件没有「已下载」提示？
超过 1GB 的文件会改用浏览器原生下载（更省内存），进度看浏览器通知栏——这是浏览器限制，功能不受影响。
Q7：聊天记录重启后没了？
正常。聊天是临时接力用的，服务端只保留最近 200 条，重启即清空。
Q8：别人能看到我的聊天/删我的文件吗？
同一 Wi-Fi 下打开页面的人都能操作——这就是「可信局域网」工具的定位。请在可信网络使用，不要把地址发给外网的人。
Q9：电脑 IP 变了怎么办？
桌面端 5 秒内会弹提示并更新二维码，手机改用新地址重开即可（已打开的旧页面会失联，属正常）。
Q10：服务停了之后，手机上已打开的页面会怎样？
约 5 秒后整页变成「无信号」测试卡画面——服务没了就无法再通信，这是网络原理；到电脑端重新启动服务，画面会自动恢复（前提是地址没变）。
Q11：对方上传的文件我这边列表迟迟看不到？
列表自动同步，正常情况下对方传完这边立刻出现；万一没刷出来点一下 ↻ 刷新（转圈表示正在拉取）。删除文件后列表也会立即刷新，不用等。
Q12：点「检查更新」提示失败？
检查更新需要电脑能访问 GitHub。失败不影响软件任何功能；也可以直接去项目的 Releases 页面手动下载最新版。
Q13：安卓手机怎么装？
到项目 Releases 页按机型下载对应安装包：arm64-v8a（绝大多数手机）/ armeabi-v7a / x86 / x86_64，文件名形如 CC-Flash-vX.Y.Z-android-arm64-v8a.apk。传到手机点开安装，系统提示「未知来源」时选择允许即可。注意 APK 与电脑端是配套的：APK 只是操作界面，真正的文件服务仍跑在电脑上——手机装的 APP 也要和电脑连同一个 Wi-Fi。
Q14：托盘里出现好几个 CC-Flash 图标？
旧版本重复启动会各自开一个进程、各占一个托盘图标。新版内置单实例守卫：重复打开只会唤起已有窗口，不会再堆积图标。若从旧版升级后残留多个图标，把它们逐个「退出」（或任务管理器结束进程）后重新打开一次即可。
Q15：怎么让软件开机自动运行？
「CC设置」→ 打开「开机自动启动」开关（默认关闭，打开时才会向系统注册登录项）。开启后每次登录电脑，服务在后台自动启动、不弹窗口。注意：请先正式安装到「应用程序」目录再开启——从 DMG 或开发目录运行时注册的是临时路径，重启后会失效。

12安全须知

请务必阅读 本工具面向可信局域网（家庭、可信办公网）。同一网络的任何人都能查看/下载/删除共享文件、发言，接口无密码。请勿在公共 Wi-Fi 使用，勿将地址发给外网人员，重要文件传完及时取走。

默认共享目录：~/CC-Flash。卸载软件前记得先把需要的文件从这里取走。
