👋 CC Flash · 保姆级使用说明

局域网高速文件互传 · 电脑开机当服务器，手机扫码就能传 · 适用于 v1.2.4（四段 tag v1.2.4.x） · 2026-11-19

1这是什么软件？

一个装在电脑上的「局域网文件驿站」：电脑启动服务后，同一 Wi-Fi 下的手机、平板、其他电脑用浏览器扫码，就能互相传文件、发消息——不用登录、不用数据线、不用装 App、不走外网（速度就是你路由器的速度）。

你能做什么举例
📷 手机照片回传电脑拍完照扫码上传，电脑立刻拿到原图
📄 电脑资料分发安装包、文档丢进共享目录，同事扫码自取
🔗 链接/文字接力电脑上的长链接发到聊天室，手机一点就开
💬 临时群聊开会时所有人扫码进聊天室，纪要即发即见
使用前提（很重要）手机和电脑必须连的是同一个 Wi-Fi / 同一个路由器。公司访客网络与办公内网隔离时互访不通。
第一次用先看介绍页侧边栏品牌旁的「ⓘ 介绍」按钮会打开全屏软件介绍页：功能一览、三步上手、技术实现与常见问题，顶栏可锚点跳转。看完点右上角 ✕ 或按 Esc 关闭。

2安装（macOS）

1
拿到安装包并按芯片选择：Apple Silicon 用 CC-Flash_x.y.z_aarch64.dmg，Intel Mac 用 CC-Flash_x.y.z_x64.dmg（版本号见文件名），双击打开。
2
把 CC-Flash 拖入「应用程序」文件夹。
3
首次打开若提示「无法验证开发者」：在启动台右键点它 → 打开 → 再点「打开」即可（仅第一次需要）。

Windows 版提供 .exe / .msi 安装包；Linux 可从源码构建；手机端用浏览器免安装访问，Android 另有 APK，iOS 用 Safari 打开电脑地址即可。

3三步上手（最快路径）

1
打开软件 —— 服务自动启动。窗口右上角出现「● 运行中」状态徽标和一行地址（如 http://192.168.1.8:1688），旁边是复制、二维码、在浏览器打开三个按钮；标题在左，地址宽度随内容自适应，窗口变窄会自动换行。三颗跳动的小圆点 = 服务活着。
2
手机扫码 —— 点顶栏的二维码按钮 ▦，用手机相机扫码；或直接在手机浏览器输入窗口里那行地址。
3
开始传 —— 手机页面点上传选照片，电脑的「共享文件」列表立刻出现；反过来电脑点文件行的分享按钮，把链接发给手机也能下载。
一句话记住电脑是驿站，浏览器是取件码：地址+端口就是一切。

4桌面端 · 消息发送

侧栏的业务入口只有「消息发送」：文件和消息在同一条时间线里。上传的文件以文件卡片出现在对话中；完整的共享文件列表收进右侧的「共享文件」抽屉。

设备即目标左侧是 Snapdrop 风格周边设备栏（本机身份卡 + 扫描雷达 + 附近设备列表，宽 200px）。点一台设备，输入栏就切换成「直发」，文字 / 文件直接送到对方节点，时间线追加本机回执；点「本机共享」或右上角「×」可取消目标，回到当前房间聊天。设备栏底部不再重复放二维码 / 复制地址——扫码用顶栏或服务中心即可。

4.1 上传文件的 5 种方式

  1. ＋ 面板上传 → 点输入栏左侧「＋」→「文件」，弹出选文件窗口（可多选）；
  2. 拖拽 → 把文件、或整个文件夹从访达拖到页面任意位置，松手即上传（文件夹保持目录结构）；
  3. 选择文件夹 → 「＋」→「文件夹」（iPhone/iPad 的 Safari 不支持选文件夹，该入口会自动隐藏，请改用多选）；
  4. 粘贴 → 截图后直接 Ctrl+V / Cmd+V；
  5. 手机上传 → 手机打开页面点「＋」上传（见第 7 节）。

上传一开始，对话里就出现文件卡片：等待中 / 上传中（进度 + 百分比 + 实时速率）/ 完成 / 失败。上传期间手机屏幕自动保持常亮，锁屏不会中断传输（最多同时传 3 个文件，其余自动排队）。同名文件永不互相覆盖：自动改名 xxx(1).zip、(2)、(3) 依次顺延，卡片上会提示「已存为…」。

4.2 文件卡片与文件组

状态卡片上能做什么
等待中显示排队位置，可点 ✕ 取消
上传中进度条 + 速率，可点 ✕ 取消；底部还有一条「正在上传 N 个」总览
完成打开 / 预览 / 下载、分享、在共享文件抽屉中定位
失败显示失败原因，可重试或取消（服务端已清理半截文件）

一次选择 / 拖入 超过 3 个文件时，会自动合并成一张「文件组」卡：显示文件数、总大小和状态，点「展开」查看每个文件的进度，避免时间线被大量文件刷屏。

4.3 共享文件抽屉

点房间头的文件夹按钮（带文件数）打开 / 收起右侧抽屉。抽屉已加宽到约 340~400px，文件名与「大小 · 月-日 时:分」字号同步加大，一行能看全；列表与上传卡片使用同一份数据。

缩略图 / 👁 预览浏览器与手机端点缩略图或「预览」即打开全屏预览（见 4.5）；桌面壳点缩略图交系统程序打开

4.4 每个操作按钮（悬停有文字提示）

📂 打开用系统默认程序打开这个文件立即打开（如图片进系统看图、文档进办公软件）

4.5 应用内预览

图片、PDF、纯文本（txt/md/log/csv）和音视频都可以直接预览：点缩略图或文件旁的「预览」按钮，打开全屏预览层，右上角「关闭」或按 Esc 即回到聊天，不会离开当前页面。PDF 在浏览器网页里直接内嵌查看；桌面壳用系统默认程序打开，手机 App 交系统浏览器打开。Office 文档、压缩包等浏览器无法渲染的类型仍需下载后查看；为安全起见 html / svg / xml 不会以网页形式内联打开。超过 2MB 的文本会提示下载后查看，避免手机内存被占满。

为什么电脑桌面端没有「下载」按钮？电脑上直接「打开」或「复制」即可取文件；「下载」和「预览」按钮出现在手机/浏览器端。这是刻意设计。

5桌面端 · 消息与未读

  • 同一 Wi-Fi 下打开页面的人（含手机）都在同一间「消息发送」房间里，消息 WebSocket 实时推送（断线自动降级为约 3 秒轮询兜底）；文字和文件卡片按时间排在同一条时间线里。
  • 改昵称：点房间头右侧的头像（显示当前昵称），回车/保存即记住。不改就自动叫「Mac Chrome-2569」这样的名字。
  • 头像：根据昵称自动分配一个 emoji，同昵称永远同头像。
  • 发链接：直接粘贴网址发送，会变成可点击的蓝色链接（电脑点开走系统浏览器）。
  • Markdown：支持标题、无序/有序列表、引用、分割线、围栏代码块，以及行内代码、粗体、斜体、删除线、[文字](链接) 和裸链接。
  • 多行输入：桌面端 Enter 发送、Shift+Enter 换行；手机端 Enter 换行，点「发送」提交。中文输入法组字期间按回车只确认候选词，不会误发。
  • 清空显示：点房间头的「清空消息」；只清掉自己窗口里的显示，别人的和服务端的记录都在。
  • 未读：页面在前台且窗口有焦点时自动已读；切到服务中心/设置或窗口失焦时，侧栏「消息发送」显示未读。聊天上翻时底部浮出「N 条新消息 · 回到底部」。
  • 聊天记录服务端保留最近 200 条（另限总量 200 万字符），并持久化到 chat-history.json，重启服务后自动恢复；「清空消息」只清本窗口显示。单条消息最多 200000 字符，输入栏会实时显示字数，超限会提示并禁止发送。

6桌面端 · 服务与设置

6.1 服务控制

控件怎么用
「● ● 运行中」徽标三颗跳动小圆点 = 服务健康；灰色「○ 已停止」= 未启动
顶栏地址组标题固定在左，运行状态 + 地址 + 复制 / 二维码 / 浏览器按钮整组靠右上；点击地址全选，复制按钮一键复制。地址宽度随内容自适应，窗口变窄时整组自动换行；副标题提示「同一 Wi-Fi 下的设备用浏览器访问下方地址即可使用」
端口默认 1688；运行中锁定；被别的程序占用会自动顺延到下一个可用端口
共享目录所有传的文件都存在这个文件夹；点「打开」直达，或点「选择」弹出系统目录框直接选取（选定即保存）；服务运行中换目录会自动「停止 → 切换 → 重启」一键完成，手机端刷新即可
💾 可用空间所在磁盘的剩余/总容量；空间不足时上传会被拒绝并提示
启动服务 停止服务 打开共享目录三个主操作按钮

6.2 手机扫码直达（常驻侧边栏）

服务运行中，侧边栏下方常驻一块白底二维码（带流光扫描动效），任意页面直接拿手机扫，不用切菜单；点击二维码可放大查看完整地址。侧边栏收起后，原地保留迷你码，鼠标悬停即浮出可扫大图。若电脑换了网络（IP 变了），地址和二维码会在 5 秒内自动更新，并弹提示「本机 IP 已变为 …，手机请改用新地址访问」——这时让手机重新扫一次即可。顶栏的二维码按钮可随时打开大图弹窗（含完整地址复制）。

6.3 桌面悬浮码（屏幕边缘的呼吸球）

除了侧边栏二维码，桌面上还有一个常驻的呼吸小圆点——它吸附在屏幕边缘、默认在左侧中部，一半藏在屏幕外，任何页面、主窗口收起后都能用：

  • 扫码：鼠标停在圆点上约 1.5 秒，二维码卡会自动滑出（标题「浏览器扫一扫」）；鼠标移开约 0.25 秒自动收起。二维码卡是预览，点它或点圆点都会打开主窗口；
  • 看状态：外圈粉环一呼一吸 = 服务运行中；停止不动 = 服务已停止（此时悬停会看到「服务已停止 / 打开主窗口启动服务」的暗色提示卡）；
  • 看提醒：有新文件传上来或来新消息时，圆点外圈会弹一个绿色小点；打开主窗口后绿点自动消失（说明你已经看到啦）；
  • 换位置：按住圆点拖到屏幕任意一边，松手自动贴边吸附；接了扩展屏也能用——拖到哪块屏就吸哪块屏，位置连同屏幕一起记住，重启软件还在原处；扩展屏暂时拔掉会先落到当前屏幕，插回去小球自动回到扩展屏上；
  • 开关：不想要它时，到「CC设置」关掉「悬浮二维码」开关——立即消失且重启后保持关闭；重新打开开关即恢复（连位置一起）。
小知识：圆点贴在屏幕顶部时会完整贴在菜单栏下沿（系统不允许窗口顶到菜单栏上面），左右和底部则是"漏一半"的半隐藏效果。

6.4 服务日志

  • loguru 风格结构化输出：精确到秒的时间戳 + 级别（INFO / SUCCESS / WARNING / ERROR 按级别着色）+ 来源 文件:行号 + 消息——谁在上传、谁在下载、谁发了什么、何时启停、谁在试配对码，一目了然；
  • 例：2026-11-04 16:12:14 | SUCCESS | server.rs:1170 - 上传完成 照片.jpg (3.2 MB, 820ms) ← 10.161.1.5 (iPhone)；
  • 新日志自动贴底跟随（上翻查历史时不打扰），标题旁显示实时条数；普通刷新类动作（页面轮询）不会刷屏；
  • 「清空日志」按钮：一键清屏，会留一条「日志已清空」标记；容量 2000 条，超出自动滚动淘汰。

6.5 皮肤设置（「CC设置」页）

「CC设置」页的「皮肤设置」卡：明暗主题模式为亮色 / 暗色 / 跟随系统分段选择（跟随系统随手机、电脑的外观自动切换）；配色五套：深空蓝 / 石墨玫瑰 / 森林薄荷 / 暗夜紫 / 墨色琥珀（默认「深空蓝 + 亮色」），点色块立即换色并记住选择，手机端页面同步换色，桌面对话气泡也跟随主题。夜间推荐「暗色 + 墨色琥珀」。

6.6 版本与更新（「CC设置」页）

  • 「关于」卡显示当前版本（本说明对应 v1.2.4，四段 tag 形如 v1.2.4.x），点「检查更新」会去 GitHub 查询最新版本（需要电脑能访问 GitHub）；
  • 有新版本会弹框对比当前/最新版本和更新说明，点「前往下载」直接打开下载页；
  • 平时不用管：软件每天最多自动静默检查一次，有新版才提醒；

7手机端使用全攻略

7.1 打开页面

相机扫桌面上的二维码 → 自动用浏览器打开。Android App 默认作为本机独立节点启动；要浏览电脑上的文件，到「CC设置 → 连接电脑」填入电脑地址。页面可以「添加到主屏幕」当快捷方式（http 局域网地址下浏览器不支持离线安装）。

7.2 页面长什么样

  • 手机 App 只有「发送 / 设置」两个标签；聊天头部有「设备」入口（点开后展开竖屏整页设备面板，不弹窗），下面才是消息区；手机浏览器没有标签、没有设备发现，仍是原来的聊天室单页；
  • 顶部：房间名「消息发送」+ 运行状态 +「清空消息」+ 文件夹按钮（共享文件数）+「⋯」更多；
  • 中部：一条对话时间线——文字气泡和上传的文件卡片按时间排列；
  • 底部：输入栏（＋ / 文字 / 发送），整个页面就是一个聊天窗口；
  • 没有悬浮球、没有第二个入口；共享文件在顶部的文件夹按钮或「＋ → 共享文件」里；
  • 服务停了或电脑地址变了，约 5 秒后整页变成「无信号」测试卡；Android 应用连本机时会尝试自动重启并重新探测端口；连电脑模式下会出现「重新启动本机服务」按钮（回到本机节点），也可到「CC设置 → 连接电脑」改地址或点「切回本机节点」。

7.3 传文件

  • 上传：点输入栏左侧「＋」→「文件」选照片/文件（可多选）；或「文件夹」整个目录上传；也可以直接粘贴截图。上传立刻在对话里出现文件卡片，显示等待 / 进度 / 完成 / 失败。
  • 下载：点文件卡片上的「下载」，或共享文件面板里的「⋯ → 下载」。手机浏览器小文件走 blob（有完成提示），大文件（>50MB，防 Safari 崩溃）交浏览器原生下载；Android 应用会打开系统浏览器下载。
  • 预览：图片、文本、音视频点缩略图或「预览」即打开全屏预览层，右上角「关闭」或按 Esc 回到聊天；PDF 在网页里内嵌查看；桌面壳用系统默认程序打开，手机 App 交系统浏览器打开。Office 文档、压缩包等需下载后查看，html/svg/xml 不会内联打开。
  • 分享：文件卡片「分享」，或共享文件面板「⋯ → 分享」；开启访问令牌时链接仅授权这一个文件、10 分钟有效、完整下载一次即失效，对方免输码。
  • 微信内打开：顶部会常驻一条引导条提示——点右上角 ⋯ 选择「在浏览器打开」，否则下载可能被微信拦截。

7.4 共享文件面板

  • 点顶部文件夹按钮，或「＋ → 共享文件」，从底部滑出全屏面板；
  • 支持排序（最新/名称/大小）、分页（每页 10 条）、全选、批量删除；
  • 每行右侧的「⋯」打开动作面板：预览（可预览类型）、下载、分享、删除；桌面端为打开、复制文件、分享、删除；
  • 点顶部「完成」或下拉关闭，回到对话。

7.5 消息与昵称

  • 点房间头右侧头像设置昵称；消息支持标题、列表、引用、代码块、行内、粗体、链接等轻量 Markdown；输入框可多行，手机端 Enter 换行、点「发送」提交；
  • 页面在前台时消息自动已读；切到设置或后台时保留未读；
  • 「清空消息」只清本机显示，不影响他人；
  • 新文件到达但没开文件面板时，文件夹按钮会点一个绿点。

7.6 共享剪贴板（电脑 ↔ 手机双向）

  • 电脑复制 → 手机粘贴：在电脑上复制一段文字，手机 App 可见时会在 1.5 秒内收到；点输入栏的「粘贴」即可直接填入，不会弹面板。
  • 手机复制 → 电脑粘贴：在手机 App 里复制文字，或打开「粘贴」面板点「发布到共享剪贴板」，电脑系统剪贴板会自动更新，直接在电脑上 Cmd+V / Ctrl+V。
  • 系统剪贴板自动同步默认关闭，在 CC设置「系统剪贴板自动同步」打开后生效；访问令牌与对方配对码会被自动排除。页面在后台时不会自动同步，避免悄悄覆盖你的剪贴板；远端内容应用后会提示「已从 X 同步剪贴板」。
  • 浏览器在 http://局域网IP 下不能自动读写系统剪贴板：点「粘贴」会直接把电脑端共享文本回填输入框；在聊天输入框长按「粘贴」时，文本也会自动回传电脑（跨设备共享需开启访问令牌）。只同步文本，上限 2 万字。
  • 注意：共享剪贴板走同一 Wi-Fi 的页面，能打开页面的人可能看到内容；公共网络请开启访问令牌，敏感内容传完点「清空」。

8托盘与退出

  • 点窗口红色关闭按钮 ≠ 退出：窗口收纳到系统托盘（菜单栏右上角图标），服务继续运行，手机照样能访问；首次收纳会弹系统通知提醒你；
  • 左键点托盘图标：直接唤出主窗口；右键打开菜单：显示主窗口 / 启动·停止服务 / 打开网页 / 退出。macOS 也可以点程序坞里的图标重新打开窗口；
  • 单实例守卫：应用已在运行时再次双击图标（桌面 / 开始菜单 / 程序坞），不会再开一个新窗口、也不会多出托盘图标，只会把已有主窗口唤到前台；
  • 开机自启（可选）：「CC设置」→ 打开「开机自动启动」（默认关闭，打开开关才注册）。开启后登录电脑时服务在后台自动启动、不弹出主窗口，点托盘或应用图标随时唤出。请从「应用程序」目录里的正式安装版开启——若从 DMG 或开发目录运行，登录自启会指向临时路径而失效；
  • 想彻底关掉：托盘菜单 →「退出」。

9皮肤与外观

「CC设置」页 → 皮肤设置：顶部选择亮色 / 暗色 / 跟随系统，下方五套配色（深空蓝 / 石墨玫瑰 / 森林薄荷 / 暗夜紫 / 墨色琥珀）即点即换、自动记忆，桌面和手机页面一起换色，桌面对话气泡也跟随主题。默认「深空蓝 + 亮色」；夜间推荐「暗色 + 墨色琥珀」。

10常见问题 FAQ

Q1：手机打开地址一直转圈 / 提示连接超时（TimedOut）？
① 确认手机和电脑连的是同一个 Wi-Fi；② 电脑如果换过网络，IP 会变——看桌面端提示的新地址，手机改用新地址；③ 试着 ping 或直接在电脑浏览器里打开该地址自检；④ 公司网络可能开了「AP 隔离」，换个热点试。
Q2：窗口右上角 × 了，手机还能用吗？
能。关窗只是收进托盘，服务还在跑；彻底退出请用托盘菜单的「退出」。
Q3：启动时提示端口被占用？
会自动换到下一个可用端口（地址栏里的端口号会变），无需处理。也可停止服务后手动改端口再启动。
Q3.5：共享文件列表去哪了？
收进了「共享文件」抽屉 / 面板：桌面点房间头的文件夹按钮或右侧抽屉，手机点顶部文件夹或「＋ → 共享文件」。排序、分页、全选、批量删除都在里面；上传的文件同时以卡片出现在对话里。
Q3.6：能直接预览文件吗？
图片、PDF、纯文本（txt/md/log/csv）和音视频都可以：点缩略图或「预览」打开全屏预览层，右上角「关闭」或按 Esc 回到聊天。PDF 在浏览器网页里内嵌查看；桌面壳用系统默认程序打开，手机 App 交系统浏览器打开；Office 文档、压缩包等浏览器无法渲染的类型仍需下载；html/svg/xml 不会以网页形式内联。超过 2MB 的文本会提示下载后查看。
Q4：上传失败提示「磁盘空间不足」？
共享目录所在磁盘满了。清理空间，或把共享目录换到别的盘（改完需重启服务）。
Q5：上传到一半断了，文件会坏吗？
不会。目录里永远不会出现残缺文件——中断的半截文件会被服务端立即清理，重新上传即为完整重传（同名文件照常自动改名顺延，不覆盖已有文件）。上传期间手机屏幕自动保持常亮，尽量从源头避免中断。
Q6：上传的文件和目录里已有的重名了怎么办？
不会被覆盖。会自动改名为 xxx(1).zip、(2)、(3) 依次顺延，原有文件永远保留；上传完成后页面会提示实际保存的名字（如「已存为 报告(1).zip」）。
Q5.1：手机的「发现」页怎么没了？
设备发现已经并进发送工作台：桌面在「消息发送」左侧设备栏，手机 App 在聊天头部「设备」；手机 / 电脑浏览器保持原聊天室，不做发现。选中设备后输入栏会变成直发，消息和文件直接送到对方节点。
Q5.2：电脑复制的内容，手机怎么粘贴？
手机 App 可见时打开输入栏「粘贴」，内容会直接填入，不会弹面板。反向同步需先在 CC设置 打开「系统剪贴板自动同步」；开启后手机复制的内容会更新电脑系统剪贴板，页面在后台时不会同步。
Q6：手机上下载大文件没有「已下载」提示？
手机浏览器里超过 50MB 的文件会改用浏览器原生流式下载（更省内存），进度看浏览器下载列表或通知栏——这是浏览器限制，功能不受影响。
Q7：聊天记录重启后还在吗？
在。服务端把最近 200 条（总量 200 万字符预算）持久化到本地，重启服务后自动恢复；超出保留上限时从最旧的开始淘汰。
Q8：别人能看到我的聊天/删我的文件吗？
同一 Wi-Fi 下打开页面的人都能操作——这就是「可信局域网」工具的定位。请在可信网络使用，不要把地址发给外网的人。半可信网络（如公司/公共 Wi-Fi）可在电脑端 CC设置 开启访问令牌：手机首次打开需输入 6 位配对码（输一次全端透明），连续输错会按来源 IP 指数退避，IPv6 下再按 /64 网段聚合（单窗上限 10 分钟），锁定期间正确码也会被拒，稍等再输即可；电脑本机不受影响。开启后分享出去的链接自带一次性授权——只能下载那一个文件、10 分钟有效，任意一次成功下载即失效，对方无需输码；关闭令牌、换新配对码或切换共享目录时旧链接全部作废，对无效链接的反复猜测会按来源 IP 限流。拷来的旧配对码会被页面自动清除，不会出现"越输越锁"。
Q9：电脑 IP 变了怎么办？
桌面端 5 秒内会弹提示并更新二维码，手机改用新地址重开即可（已打开的旧页面会失联，属正常）。Android 应用：连本机模式下会自动重新探测端口；连电脑模式下到「CC设置 → 连接电脑」填新地址，或点「切回本机节点」。地址只收 IP 或 localhost，xxx.local 会被服务端拒绝（防 DNS 重绑定）。
Q10：服务停了之后，手机上已打开的页面会怎样？
约 5 秒后整页变成「无信号」测试卡画面——服务没了就无法再通信，这是网络原理；到电脑端重新启动服务，画面会自动恢复（前提是地址没变）。
Q11：对方上传的文件我这边列表迟迟看不到？
列表自动同步，正常情况下对方传完这边立刻出现；万一没刷出来点一下 ↻ 刷新（转圈表示正在拉取）。删除文件后列表也会立即刷新，不用等。
Q12：点「检查更新」提示失败？
检查更新需要电脑能访问 GitHub。失败不影响软件任何功能；也可以直接去项目的 Releases 页面手动下载最新版。
Q13：安卓手机怎么装？
到项目 Releases 页下载唯一的 Android 安装包 CC-Flash-vX.Y.Z-android-arm64-v8a.apk（覆盖 Android 5+ 主流 64 位机型，不再需要选 CPU 架构）。传到手机点开安装，系统提示「未知来源」时选择允许即可。安装后 App 默认作为本机独立节点运行文件服务与聊天（只监听 127.0.0.1，同一 Wi-Fi 的其他设备访问不到；Android 用前台服务通知保活）；需要浏览电脑文件时，到「CC设置 → 本机服务 → 连接电脑」输入电脑地址，或点「切回本机节点」返回独立模式。要让其他设备访问手机上的共享目录，需在 CC设置 手动开启局域网访问（建议同时开启访问令牌），然后点「重启服务」生效。地址只支持 IP / localhost（不支持 xxx.local）。
Q14：托盘里出现好几个 CC-Flash 图标？
旧版本重复启动会各自开一个进程、各占一个托盘图标。新版内置单实例守卫：重复打开只会唤起已有窗口，不会再堆积图标。若从旧版升级后残留多个图标，把它们逐个「退出」（或任务管理器结束进程）后重新打开一次即可。
Q15：怎么让软件开机自动运行？
「CC设置」→ 打开「开机自动启动」开关（默认关闭，打开时才会向系统注册登录项）。开启后每次登录电脑，服务在后台自动启动、不弹窗口。注意：请先正式安装到「应用程序」目录再开启——从 DMG 或开发目录运行时注册的是临时路径，重启后会失效。
Q16：手机连不上，提示超时？
十有八九是 Windows 防火墙。首次启动服务时系统会弹「允许 CC-Flash 访问网络」的对话框——如果当时点了「取消」，手机就连不上了。修复：控制面板 → Windows Defender 防火墙 → 允许应用通过，勾选 CC-Flash 的「专用网络」；或直接重装一次、弹窗时点「允许」。其次检查手机和电脑是否同一 Wi-Fi（有些访客网络会隔离设备互相访问）。
Q17：Windows 打开安装包提示"已保护你的电脑"（SmartScreen）？
安装包未做付费代码签名，SmartScreen 会拦截，属正常。三步放行：点「更多信息」 → 点「仍要运行」 → 按提示完成安装。只从项目官方 Releases 页下载即可放心运行。
Q18：macOS 打开提示"已损坏，无法打开"或"无法验证开发者"？
未签名未公证的正常现象，两种放行方式：方式一——首次打开时按住 Control 点击图标 → 菜单选「打开」→ 再点「打开」；方式二——打开「系统设置 → 隐私与安全性」，下滑找到被拦截的 CC-Flash，点「仍要打开」。若提示「已损坏」且方式一无效，可打开终端执行：xattr -dr com.apple.quarantine /Applications/CC-Flash.app。
Q19：开着公司 VPN / 代理（科学上网）时二维码扫不开？
服务会自动避开 VPN 虚拟网卡、优先展示真实局域网地址；若地址仍不对，看桌面端二维码弹窗里是否列出了多个候选地址——点选与手机同网段的那个即可。另外注意：连着不可信网络（公司 VPN、酒店 Wi-Fi）时共享目录对同网段可见，请用完及时停止服务。
Q20：屏幕边缘的呼吸小球不见了 / 想关掉它？
小球的开关在「CC设置 → 悬浮二维码」（唯一关闭入口，圆点上没有 ✕）。关了立即消失且重启保持关闭；重新打开就恢复，连你上次拖到的位置一起恢复。打开后小球在左侧中部贴边（漏一半）；鼠标停 1.5 秒出码，按住可拖到任意边缘——多显示器也行：拖到哪块屏就吸哪块屏，重启回原处（扩展屏拔掉会先落当前屏，插回自动归位）；Windows 下主屏与扩展屏缩放比例不同（如 100% + 150%）也能正确落位与悬停。
Q21：小球外圈的绿点是什么意思？
有新文件传上来或来新消息时出现的提醒点，弹一下表示"有新的"。打开主窗口后自动消失（你已经在软件里了，不需要再提醒）；什么都不发生时绿点是隐藏的，不会常驻打扰。

12安全须知

请务必阅读 本工具面向可信局域网（家庭、可信办公网）。桌面端默认同一网络的任何人都能查看/下载/删除共享文件、发言；半可信网络请在「CC设置」关闭局域网访问（仅本机可访问），或开启访问令牌（6 位配对码 + 按来源 IP 指数退避，IPv6 按 /64 聚合、单窗上限 10 分钟，公网来源还有全局失败预算，本机免输），分享链接为单文件一次性票据（绑定文件大小/ETag，文件删除或同名重传后立即失效）。移动 App 默认安全模式：只监听 127.0.0.1，并自动生成本机访问令牌（同机其他 App 也无法直连）；其他设备访问不到，需在 CC设置 手动开启「局域网访问」并重启服务。服务端还有上传 / 下载 / WebSocket 并发闸并叠加单来源配额（上传 4 / 下载 8）与下载 45s 空闲超时，控制接口拒绝跨站请求，静态页面带防点击劫持头与完整脚本级 CSP，停服时在途上传会回滚半截文件；系统剪贴板自动同步默认关闭，开启后也只在页面可见时同步，访问令牌/配对码自动排除，跨设备读取共享剪贴板需要访问令牌；Windows 上若成品被占用无法删除，会保留上传标记等下次启动清理，不会把半截文件当完整件。公网来源（含全局 IPv6）在未开启访问令牌时会被服务端直接拒绝；请勿在公共 Wi-Fi 使用，勿将地址发给外网人员，重要文件传完及时取走。

默认共享目录：~/CC-Flash。卸载软件前记得先把需要的文件从这里取走。
