CC Flash · 整个过程历史改动记录

时段：2026-11-20 至 2026-11-21 · 版本：v1.2.4 全量复审收尾 · 与《技术实现文档》《需求设计文档》《后期规划》配套阅读
本段主题对桌面壳、手机 App、电脑/手机浏览器与服务端做全量复审，按「安全 → 可用性 → 平台/发布 → 文档」修复审查项。同时把 README、docs 全目录与应用内介绍页校准到最新代码：侧栏 176px、Windows 仅 NSIS exe、Android 7.0+、雷达去掉「扫描雷达」标题、浏览器不提供跨设备直发。

一、安全

  • 移动端令牌全来源校验：启用访问令牌后，除回环外本机 Wi-Fi IP 也必须带码，堵住同机其他 App 改连 192.168.x.x 绕过 PIN 的口子；App 壳通过可信 Tauri 通道自动带 X-Access-Pin，正常使用无感。
  • 浏览器跨设备直发入口隐藏：浏览器静态页 CSP 不为任意 http: 目标放行，手动发送/直发在网页端显式提示「请使用桌面端或手机 App」，避免 100% 失败却误报「对方离线」。
  • CSP 补齐 wss:：Tauri 壳与浏览器静态页的 connect-src 同时允许 ws:/wss:，HTTPS 反代下安装 PWA 后 WebSocket 不再被拦、实时推送不再降级为轮询。
  • 发布链路 fail-closed：Release 查询只把 404 当 missing，网络/API/权限错误直接失败；已公开 Release 或陈旧 main 不再被 API 推送覆盖；第三方 Actions 固定 commit SHA；macOS/Windows 构建后复核 codesign/stapler 与 Authenticode，签名/公证不完整不公开。
  • 下载/上传/聊天并发闸：下载许可与单来源槽位改由独立看门狗持有，客户端不读响应或 45s 无进展时无条件 abort 并归还；聊天读 4 / 写 8、文件遍历 2 的并发上限，单来源上传 4 / 下载 8，下载与上传槽位分开计数。

三、平台与发布

  • Android：产物统一为 arm64-v8a 单包、minSdk 24（Android 7.0+）；旧 WebView 由启动页内核检查兜底提示升级，不再宣称 Android 5/6 可用。
  • iOS：明确不交付原生安装包（无 gen/apple、签名、multicast entitlement 与后台模式）；build-all.sh ios 默认拒绝，iOS 用户使用 Safari 网页版。
  • Windows：只发 NSIS .exe，不再生成/发布 msi；文档与 Release 门禁同步。
  • CI 修正：Android 的 dtolnay/rust-toolchain 步骤原有两个 with: 键，YAML 解析时会丢弃 toolchain；已合并为同时设置 toolchain 与 targets。

五、交互自测与响应式收尾（2026-11-21）

  • 窄窗设备面板：原 ≤430px 才整页覆盖，桌面窗口最小 560px 时 360px 侧栏会把聊天区压到 200px、输入栏不可用；改为 ≤760px 整页覆盖，761–980px 仍保留 360px 侧栏（聊天区 ≥400px）。
  • 手动发送：取消不再误报「发送超时」；失败/取消保留地址、文本与已选文件，重开可直接重试；只有全部成功才关闭弹框，部分成功只清掉成功的部分。
  • 提示位置：toast 在底部输入栏存在时抬到输入栏上方，不再遮挡发送按钮。
  • 窄屏输入栏：占位文案缩短为「说点什么…（Enter 发送）」（触屏为「说点什么…」），360/390px 不再换行裁切；设备面板开合后重算 textarea 高度，避免 WebKit 半屏高输入框残留。
  • 状态与日志：已停止状态收成单个静态灰点（三灰点与加载中太像）；服务日志强制换行，不再横向裁切；运行中介绍页顶部按钮改为「打开服务中心」。
