复用与边界

  • 复用 当前房间头、共享文件抽屉、输入栏、＋面板
  • 复用 PIN、一次性票据、二维码、共享目录
  • 复用 现有 HTTP REST，不引入 WebRTC
  • 不做 极简首屏重构，避免大改
  • 不做 云端中继、持续同步、通知遥控

为什么这样最省

Snapdrop/PairDrop 的“打开即用”不一定要重做首页；在现有页面上加一条附近设备 + 一个安装入口，就能把最短路径从「扫码 → 找地址」缩短到「看到设备 → 点击」。

LocalSend 的接收确认依赖设备会话，属于协议层改动；先用 P1 标注，避免把首版拖成重构。
