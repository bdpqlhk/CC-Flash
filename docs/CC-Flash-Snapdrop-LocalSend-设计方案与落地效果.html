附近设备自动发现

同一局域网自动列出在线设备；桌面/客户端走 mDNS/UDP，浏览器端保留扫码与最近连接。

落地：首屏直接点设备，不再先找 IP；设备显示在线/忙碌/最近活跃。
LocalSend

接收确认 + 信任设备

陌生设备首次发送需接收方确认；可勾选「信任此设备」，之后自动接收。

落地：接收弹窗展示发送方、文件名；拒绝即结束，信任后免打扰。
CC-Flash

极简首屏

首屏只保留设备、拖拽区、发送按钮；聊天/共享文件/服务中心收进「更多」。

落地：打开即传，功能不丢，只是不占主路径。
Snapdrop · LocalSend

分享给无客户端设备

生成网页链接/二维码，对方浏览器打开即可接收；复用现有访问令牌与一次性票据。

落地：不要求对方安装 App；链接可控、可作废。
Snapdrop

PWA 安装体验

手机浏览器添加到主屏幕：独立图标、启动图、记住电脑地址、离线壳。

落地：第二次打开不用扫码/输地址；服务不可用时显示连接引导而非白屏。
LocalSend

文本 / 剪贴板

发送区切换文件、文件夹、文本、剪贴板；链接、验证码、地址一粘贴即发。

落地：不必为了发一段文字切到聊天；文件与文本共用同一套接收确认。
LocalSend

最近传输 / 收藏

收藏设备置顶；最近成功/失败记录可一键重发。

落地：减少重复操作；失败项保留重试入口。
LocalSend

忙碌 / 拒绝状态

设备列表展示在线、忙碌、最近活跃；接收方可拒绝并给出原因。

落地：发送前就知道对方是否可接收，减少“发了没反应”。
