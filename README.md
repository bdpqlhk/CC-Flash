# CC Flash · 局域网高速文件互传

[English](./README.en.md) | **简体中文**

电脑开机当服务器，手机扫码就能传。同一 Wi-Fi 下的手机、平板、电脑用浏览器互相传文件、发消息——**零登录、零公网、开箱即用**，速度就是路由器的速度。

技术栈：**Tauri 2 + Rust(axum) + Vue3 + Vite**（当前应用版本 **1.2.6**，2026-11-23 全量复审 + 全功能自测 + 产物瘦身）。前端主包 **322,224 B（约 315 KiB）**，二维码库按需另加载 24,533 B，CSS **134,734 B（约 132 KiB）**，`dist` 合计 **541,530 B（约 529 KiB）**；Rust 二进制 **arm64 4,084,368 B / x64 5,045,392 B**（strip + fat LTO + opt-level=z + panic=abort）。Windows 安装包改用 WebView2 **downloadBootstrapper**（不再内嵌 ~1.8 MB 引导器），Android 仅保留中英文资源并只发 arm64-v8a 单包；macOS 分架构 dmg **2.73–2.85 MiB** / .app **4.12 MiB（arm64）/ 5.03 MiB（x64）**（以 Release 产物为准）。

## 功能特性

- 💬 **对话式传输（唯一入口「传输」）**：文件和消息放进同一条时间线——上传即出现**文件卡片**（等待 / 上传中 / 完成 / 失败、实时进度与速率、取消 / 重试），批量上传自动合并为**文件组**；文字仍是左右气泡，支持昵称、头像、**Markdown**（标题 / 列表 / 引用 / 分割线 / 代码块 / 行内代码 / 粗体 / 斜体 / 删除线 / 链接）与**多行输入**（桌面 Enter 发送、Shift+Enter 换行；手机 Enter 换行后点发送）、未读；单条消息上限 **200000 字符**（Unicode 字符计数，输入栏实时显示，超限禁止发送并明确提示）。完整共享文件列表收进**右侧抽屉（340~400px，字号加大、分页占满底栏）/ 手机 App「文件」页**，排序、分页、全选、批量删除、打开 / 复制 / 下载 / 分享全部保留，缩略图与「预览」按钮可直接预览
- 📁 **文件能力**：拖拽 / 点击 / `Ctrl+V` / 整个文件夹上传（保持目录结构），大文件**单请求整文件直传**（流式落盘、零内存占用；失败 / 超时 / 停服即时回滚半截文件），上传期间**锁屏自动保活**（客户端 3 并发队列 + 无进展看门狗；服务端上传 / 下载 / WebSocket 并发闸 16 / 32 / 64），同名文件**永不覆盖**（自动 `报告(1).zip` 顺延），流式下载支持 Range 断点续传（含 `bytes=-N` 后缀区间），上传必须带 `X-File-Size` 或 `Content-Length`（服务端用它做完整性校验，缺失返回 411），中文文件名完美支持
- 🔍 **应用内文件预览**：图片 / PDF / 文本（txt/md/log/csv）/ 音视频点击缩略图或「预览」即全屏查看，右上角「关闭」或 Esc 直接回到聊天；Office 文档、压缩包等浏览器无法渲染的类型仍需下载；html/svg/xml 不会以网页形式内联打开
- 💠 **桌面悬浮码**：置顶透明呼吸圆点吸附屏幕边缘（默认左侧中部，**位置持久化重启不丢**），珊瑚呼吸环 + 取景框 CC 徽章；指针停留 1.5 秒滑出「浏览器扫一扫」预览卡、移开即收；**外圈呼吸 = 服务运行中、静止 = 已停止**；外圈绿点（与呼吸环同组随环缩放）提示新文件 / 新消息（主窗打开自动隐藏并清零）；按住拖动自动吸附最近边，**支持扩展屏**（拖到哪块屏吸哪块屏，位置连同显示器一起记忆、重启回原屏；Windows 混合 DPI 下也按目标屏缩放正确落位），关闭入口仅在 CC设置
- 🖥 **服务中心**：启停/端口/磁盘空间一目了然，**loguru 风格结构化日志**（INFO·SUCCESS·WARNING·ERROR 级别着色 / 来源 文件:行号 / 贴底跟随），问题一眼定位
- 📱 **四种运行形态**：桌面壳（侧栏 + 共享文件抽屉 + 托盘/悬浮码；顶栏标题居左，运行状态 + 地址 + 复制 / 二维码 / 浏览器按钮整组靠右上，地址宽度随内容、窄屏自动换行）/ 电脑浏览器（顶部栏 + 抽屉）/ 手机浏览器（单列 + 原聊天室单页，无底部标签/发现/设置）/ 手机端 App（**独立节点**：本机运行文件服务与聊天，可被同网段设备发现），共用同一条时间线与同一套组件；桌面端支持 macOS 11+ / Windows / Linux（Linux 从源码构建），手机端提供 Android APK，iOS 不提供安装包、用 Safari 打开电脑地址；微信内置浏览器会提示点右上角「在浏览器打开」；手机 App 始终开放局域网并自动生成本机访问令牌（同网段设备需配对码），不再提供「局域网访问」开关；Android 用前台服务保活，iOS 未交付
- 📱 **消息工作台（设备选择并入发送页）**：桌面「消息发送」左侧是 Snapdrop 风格周边设备栏（本机身份卡 + 雷达盘 + 附近设备列表，在线 / 忙碌 / 最近活跃），点设备即选中发送目标，输入栏切换为「直发」，时间线追加本机回执；手机 App 为「发送 / 设备 / 文件 / 设置」四页（底部四标签）：发送页是对话与直发，设备页是雷达 + 设备清单 + 手动发送，文件页是共享文件 manifest，设置页承载访问令牌 / 剪贴板 / 重启 / 外观；窄窗桌面在聊天头部显示「设备」入口：761–980px 展开 360px 竖屏侧栏，≤760px 整页覆盖（聊天列表/输入栏隐藏，不弹窗），选中设备自动收起；宽屏桌面仍用左侧 200px 设备栏。聊天室、文件和共享剪贴板仍在同一条时间线；设备栏顶部可收起/展开，附近设备区有独立扫描按钮；本机身份卡右上角的时钟按钮打开传输历史弹框；点设备或「手动发送」都会打开统一发送面板（文件 / 文件夹 / 文本 / 剪贴板四标签，拖入区 + 已选状态 + 发送按钮），手动模式可输入 IP:端口；发送失败提示与对方配对码弹框显示在面板之上；手机 App 文件页的上传固定加入本机共享，不会沿用发送页的直发目标；手机/电脑浏览器保持无发现的原始聊天室单页；桌面侧栏收窄到 176px、设备栏 200px、共享文件抽屉 320~380px，981~1180px 宽度下抽屉改为带遮罩的覆盖层
- 📋 **共享剪贴板（本机服务内共享，可选）**：系统剪贴板自动同步**默认关闭**，在 CC设置「系统剪贴板自动同步」打开后，App 在页面可见时把本机剪贴板写进**本机服务**的共享槽，并把共享槽变化写回本机剪贴板；浏览器访问同一台电脑/手机的地址时共用这个槽（电脑复制 → 手机浏览器可粘贴；手机浏览器在聊天框粘贴 → 回传电脑）。**电脑 App 与手机 App 是两个独立节点，不会自动互通**：需要跨 App 投递时，用设备页发送面板的「剪贴板」标签发给对方。所有文本（含令牌/验证码）都会同步；公共网络请自行判断是否开启。浏览器在 `http://` 局域网地址下不能自动读写系统剪贴板：点「粘贴」直接把本机服务共享文本回填输入框；在**聊天输入框**长按粘贴的文本会回传共享槽（其他输入框不外发）。2 万字上限，只同步文本
- 📲 **PWA**：`https` 或 `localhost` 下可安装为独立应用（manifest + Service Worker 离线壳 + 更新提示）；`http://局域网IP` 不是安全上下文，浏览器内核直接禁用 Service Worker 与安装能力，此时提供「添加到主屏幕」快捷方式指引（iOS Safari 同样支持）
- 📡 **附近设备**：同一 Wi-Fi 下的 CC Flash 节点通过 UDP 多播（IPv4 `239.255.42.99:53318` + IPv6 link-local `ff02::ccf1:53318`）+ 广播自动发现，**逐网卡指定多播出口**（Wi-Fi + VPN/虚拟网卡时不再走错接口），每 3s 宣告自身，启动/手动刷新立即主动 probe；30s TTL + 正常退出 bye；新设备/忙碌/昵称变化即时推 `devices:presence`，普通心跳每 3s 合并推，服务端下发 `online`（12s 宽限）；已知 peer 每 3s 单播 announce、5s 单播 probe，前端实时应用并保留轮询兜底；发现端口 53318-53321 自动顺延；对来源地址做单播回包（单向通路的 AP 隔离也能互相补齐）；雷达区域可点击主动扫描，点设备圆点才是选择发送目标；缓存最近设备地址，多播被过滤时会向历史设备发单播心跳/probe；/24 全扫只在用户明确点击扫描时触发；空设备列表按 macOS / Windows 给出网络权限/防火墙指引；设备列表展示在线/忙碌/最近活跃与收藏置顶；**发现只在桌面端和手机 App 内进行**，浏览器不再请求 `/api/devices`、不发 `/api/hello`，也不会出现在可发送列表（避免"点得到、连不上"）；Android 持有 MulticastLock 保证接收；UDP 报文带来源 IP 校验与端口下限，前端只允许向私网地址投递。**浏览器页面不提供跨设备直发入口（跨源请求会被 connect-src 拦截，故 UI 明确隐藏）**；服务端仍对恶意跨域页面只允许投递类 POST，读取、删除、生成分享票据拒绝。桌面/移动 App 壳可直发；对方开启访问令牌时按设备稳定 id 记忆配对码
- 🗂 **原生目录选择**：共享目录点「选择」弹出系统目录框，即选即存
- 🎨 **主题系统**：亮色 / 暗色 / 跟随系统三种模式（随系统外观自动切换）× **6 套配色**（**信号台** / 深空蓝 / 石墨玫瑰 / 森林薄荷 / 暗夜紫 / 墨色琥珀），默认**信号台暗色**，即点即换、即时生效，桌面对话气泡跟随主题
- 🛡 **安全防护**：路径穿越双重防护、Windows 删除/下载拒绝尾随点/空格/ADS 别名并按 canonical 真实名做在途/标记校验、浏览器跨源拦截（DNS 重绑定/CSRF，Host 仅认 IP/localhost；控制接口额外拒绝 `Sec-Fetch-Site: cross-site`，防 `<a ping>` 停服/清日志）、聊天消息转义防 XSS、静态页面补 `nosniff / SAMEORIGIN` 与**完整脚本级 CSP**（`script-src 'self'`、`connect-src 'self' ws: wss:`、`object-src 'none'`、`frame-ancestors 'self'`）防点击劫持/XSS、上传磁盘预检 + 256MB 安全余量、可选**访问令牌**（6 位 CSPRNG 配对码 + 按来源 IP 指数退避 + **公网来源全局失败预算**防前缀轮换爆破，输一次全端透明，本机豁免；配对码：HTTP 请求走请求头，WebSocket 握手走查询参数（浏览器无法自定义头），轮换后旧码自动清除、不再自锁；独立 enabled 标记与码值分离，读取失败/码值丢失 fail-closed 重新生成并原子写入；明确关闭后重启不再复活）、分享链接**一次性票据**（12 位十六进制 token、绑定文件大小/ETag、10 分钟有效、下载即焚；文件删除或同名重传后立即失效；满额拒绝新票而非驱逐旧票）、缩略图/预览使用短时媒体会话令牌（10 分钟、绑定来源 IP；长期 PIN 不进入 `<img>/<video>/<iframe>` URL），下载响应带 `Referrer-Policy: no-referrer`、上传 / 下载 / WebSocket 并发闸（16 / 32 / 64）并叠加**单来源并发配额**（上传 4、下载 8；IPv6 按 /64 聚合）与**下载 45s 空闲超时；看门狗独立持有许可，半开/不读响应也会释放**、票据/文件指纹/删除标记检查与上传目录预检走 `spawn_blocking`、审计日志为 warn 预留 200 条且成功下载/上传/删除按来源准入、聊天读取/写入分别限并发且落盘失败不推进序号、聊天/剪贴板落盘移出 async worker 且按序号串行、启动清理对损坏残留改名 `.incomplete` 不直接删除、偏好原子写、删除不跟随符号链接、发现 bye 需携带本次 announce 的会话令牌（降低盲伪造驱逐）、**系统剪贴板同步默认关闭**（开启后任何文本都会同步，不做内容过滤）、**桌面始终开放局域网（CC设置不再提供开关）**、**移动 App 始终开放局域网且自动生成本机访问令牌（移动端不可关闭）；启用令牌后对所有来源（含本机网卡 IP）强制校验**（同机其他 App 也无法绕过）

## 快速开始

### 用户（下载安装包）

前往 [Releases 页面](https://github.com/bdpqlhk/CC-Flash/releases) 下载对应平台安装包：

- macOS：按芯片选 `.dmg` —— Apple Silicon 用 `_aarch64.dmg`、Intel 用 `_x64.dmg`，双击拖入「应用程序」
- Windows：下载 `.exe` 安装包
- Android：只提供一个 `arm64-v8a` APK，覆盖 Android 7.0+（minSdk 24）主流 64 位机型（不再分发 x86 / 32 位分包）
- Linux：从源码构建（`npm run tauri build`），CI 暂未发布 Linux 安装包

打开软件服务即自动启动（默认端口 1688，被占用自动顺延），手机扫码或输入窗口里的地址即可使用。界面只有一个「传输」入口：上传的文件会以卡片出现在对话里，完整共享文件在右侧抽屉（340~400px，手机 App 为「文件」页），缩略图与「预览」按钮可直接预览。Android App 作为独立本机节点运行文件服务与聊天；同网段设备可在「周边设备」发现手机，手机也可在电脑的周边设备列表中被发现。

### 开发者（源码构建）

```bash
# 前置：Rust 1.77+ / Node.js 18+ / macOS 需 Xcode CLT；Windows 需 MSVC Build Tools + WebView2
npm install
npm run tauri dev      # 开发运行：前端热更 + Rust 增量编译
npm run check          # cargo check 快速校验 Rust 编译
npm run tauri build    # 发布构建：自动产出 .app / .dmg / .exe
```

## 配置说明

- **服务端**（`src-tauri/src/config.rs`）：端口与顺延范围、聊天保留条数、昵称/消息长度上限、日志容量、共享目录等，是运行参数的唯一事实源；
- **下发机制**：`GET /api/info` 与桌面端状态接口均携带 `version` 与 `config` 字段，网页端启动后自动跟随服务端参数——改 Rust 配置并重启服务即可，无需重新构建前端；
- **前端**（`src/config.js`）：仅承载纯界面行为（轮询兜底值、分页大小、话术文案、存储键等），与服务端约定项以 `[同步: …]` 注释互相指向；
- **版本号**：手动只需改 `src-tauri/Cargo.toml`；`release.sh` 发版时会自动同步 `src/config.js` 兜底版本、`package.json` 与 Android `versionCode`，桌面端展示、更新检查、接口下发全部同源。

## 发版（维护者）

```bash
./scripts/release.sh 1.2.2.1 "feat: 更新说明"
```

版本号支持 `X.Y.Z` 与四段 `X.Y.Z.W`：**git tag 使用完整四段（如 `v1.2.2.1`）**，第四段是同一应用版本内的构建号；应用版本（Cargo.toml / 安装包）取前三段（`1.2.2`），CI 会校验四段 tag 的前三位与 `Cargo.toml` 一致，并额外校验 `package.json`、`config.js` 兜底版本与 Android `versionCode` 是否同步。`release.sh` 同时按 `major×10^7 + minor×10^5 + patch×10^2 + build` 计算 Android `versionCode`（上限 2.1e9），保证同版本迭代可覆盖安装。

自动完成：升版本（Cargo.toml 唯一来源）→ 同步兜底版本 / `package.json` / Android `versionCode` → 提交 → 打标签 → 推送 → CI 三平台构建并挂到 Release。

Android 产物说明：

- 必须配置 `ANDROID_KEYSTORE_BASE64 / ANDROID_KEYSTORE_PASSWORD / ANDROID_KEY_ALIAS / ANDROID_KEY_PASSWORD` 四个 Secrets，走 **release 签名**（证书固定，版本间可覆盖安装），只构建 `arm64-v8a` 单包；**四个任一缺失 CI 直接失败** —— 正式 Release 绝不允许 debug 包混入（debuggable、每次签名不同，用户无法覆盖升级）；
- Release 采用「**全部构建成功才发布**」策略：desktop 与 APK 先上传到草稿，两者全绿后自动 Publish；任一失败则保持草稿（修复后重跑 publish job 或手动 Publish）；Android 上传前会校验 Release 仍为草稿，避免重跑已发布 tag 时把新 APK 写进线上正式版；
- R8 已配置 keep 规则与 `SourceFile,LineNumberTable`，崩溃栈保留可读行号；Gradle 的 NDK 版本跟随 `NDK_HOME`，与 Rust 侧编译保持一致。
- **代码签名：有证书则签名/公证，缺证书时照常发布并标注**。workflow 预留 `APPLE_CERTIFICATE / APPLE_SIGNING_IDENTITY / APPLE_ID / APPLE_PASSWORD / APPLE_TEAM_ID` 与 `WINDOWS_CERTIFICATE / WINDOWS_CERTIFICATE_PASSWORD`；配置后自动签名/公证，桌面 job 再用 `codesign/stapler/signtool` 复核。**缺少证书时 publish job 只打 `::warning::` 并继续发布未签名/未公证包**，Release 说明中需注明 macOS 首次打开右键「打开」、Windows SmartScreen 选「更多信息 → 仍要运行」。空 Secret 不会注入构建环境，避免 Tauri 对空证书报 `Unable to decode`；Release 查询只把 404 当 missing，第三方 Actions 固定 commit SHA。**当前仓库只配置了 Android 签名 Secrets，macOS/Windows 产物为未签名包。**
- 本地 `./scripts/build-all.sh android` 的 release 构建会校验 `CC_KEYSTORE_*`；缺证书直接失败，不再把 unsigned APK 当成功产物。

macOS 按架构出**双包**：`_aarch64.dmg`（Apple Silicon）与 `_x64.dmg`（Intel），单包约 2.73 MiB；Windows 只出 **NSIS exe**，Android 只出 **arm64-v8a APK**。

> Android 端共享目录默认位于应用专属存储（无需存储权限）。当前上传为**单请求整文件直传**：中断后需重新选择文件上传（半截文件即时清理；Windows 上若成品被占用无法删除，会保留 `.ccup` 标记等下次启动清理，绝不让半截文件"转正"）；7 天清理只回收**带匹配会话指纹**的 v1.1.5-1.1.7 旧版 `.ccpart` 断点，普通同名 `.ccpart` 用户文件仍可见、不会被静默删除。下载侧 Range 断点续传使用 `ETag + If-Range`：同名文件被替换后不会把旧前缀拼到新内容上；支持 `bytes=N-`、`N-M` 与 `-N` 后缀区间。

> **iOS 说明**：当前不提供 iOS 安装包（需 Apple 开发者账号与签名证书；`gen/apple` 工程与本地网络权限声明尚未生成，open_url 等壳能力也未适配）。iOS 用户请直接用 Safari 打开电脑端地址使用网页版；`./scripts/build-all.sh ios` 默认直接拒绝（设置 `CCFLASH_IOS_EXPERIMENTAL=1` 才进入实验构建；当前没有 `gen/apple`、multicast entitlement、后台模式与签名，不能作为正式 iOS 包）。

> **macOS 说明**：最低 macOS 11.0（前端构建目标 ES2021 需要 Safari 14+ 内核）。macOS 15 (Sequoia) 首次运行会请求本地网络权限，用途说明由 `src-tauri/Info.plist` 提供；若误点拒绝，到「系统设置 → 隐私与安全性 → 本地网络」重新打开。

## 安全须知

本工具面向**可信局域网**（家庭、可信办公网）：桌面端默认同一网络的任何人都能查看/下载/删除共享文件、发言。半可信网络请开启**访问令牌**（桌面端始终开放局域网）——其他设备首次打开输入 6 位配对码即可（输一次全端透明；连续输错会按来源 IP 指数退避锁定；公网来源还受全局失败预算约束，防止轮换 IPv6 前缀爆破；电脑本机不受影响）。开启后分享出去的链接自带**一次性授权**——只能下载那一个文件、10 分钟有效、下载即焚，对方无需输码；关闭令牌、轮换配对码、切换共享目录或删除文件时旧票据同步作废，无效票据尝试会按来源 IP 限流。服务端对上传 / 下载 / WebSocket 分别设 16 / 32 / 64 并发上限，并叠加单来源配额（上传 4 / 下载 8；IPv6 按 /64 聚合）与下载 45s 空闲超时；静态页面下发完整脚本级 CSP；删除操作不跟随符号链接。电脑地址请使用 IP（服务端为防 DNS 重绑定不接受 `*.local` 域名）。**公网来源（含全局 IPv6）在未开启访问令牌时会被直接拒绝**，但请仍勿将服务地址暴露给外网。

- **移动 App 始终开放局域网 + 本机令牌**：App 启动即监听局域网，同一 Wi-Fi 的设备可在「周边设备」发现；同时 App **自动生成本机访问令牌**（Android 的 127.0.0.1 不按应用隔离，没有令牌时同机任意 App 都能直连本机服务）。壳内通过受信任的 Tauri 通道自动取码，同机其他 App 拿不到码；同网段设备需输入配对码。CC设置不再提供「局域网访问」开关；访问令牌在移动端不可关闭。
- **桌面端与移动端都始终开放局域网**：CC设置 不再提供「局域网访问」开关（历史上关过安全模式的偏好也不再生效）；移动端用自动生成本机访问令牌保护。
- **系统剪贴板同步默认关闭**：开启后只会把本机剪贴板同步到**本机服务**的共享槽，供打开本机地址的浏览器/客户端使用；电脑 App 与手机 App 是独立节点，跨 App 请用发送面板「剪贴板」投递。所有文本（含令牌/验证码）都会同步。公共 Wi-Fi 下建议关闭。
- 手机 App 的「附近设备」投递内容会进入对方公共聊天与共享目录，同网段可见，勿发敏感内容。
- **VPN / 远程组网视为局域网**：`10/8`、`172.16/12`、`192.168/16`、`100.64/10`（运营商 NAT / Tailscale）与 IPv6 ULA/link-local 都按私网处理，无令牌时可直接访问。连着公司 VPN 或共享 Tailscale 网络时，请确认网段内其他主机可信，否则保持服务停止或开启令牌。地址/二维码会自动避开 VPN 虚拟网卡优先展示真实局域网 IP（多候选时在二维码弹窗中点选）。
- **Windows 防火墙**：首次监听端口时系统会弹出网络授权，请允许「专用网络」；误点拒绝会导致手机连不上，可在 Windows Defender 防火墙中为 CC Flash 手动添加允许规则（TCP 1688 或实际顺延端口；附近设备发现还需要 **UDP 53318-53321** 入站/出站）。
